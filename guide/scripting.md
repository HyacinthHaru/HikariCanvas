# 积木脚本

让招牌「有事发生就自动做点什么」——有人进服就广播、列车到点就闪一下、玩家靠近就播声音、比分变了就改文字。全靠拖积木，不写代码。脚本在后台跑，不影响画面流畅。

每条规则的结构都一样：**一顶帽子**（什么时候触发）+ **一串积木**（依次要做的事）。一面招牌可以挂很多条规则。

## 打开积木编辑器

在浏览器编辑器顶部点 **拼图图标**，弹出全屏的积木画布。

![积木编辑器全貌：左侧规则列表与积木库、中间画布、右上试跑与关闭](/images/guide-scripting-01-overview.png)

画面分几块：

| 区域 | 作用 |
|---|---|
| 左上 规则列表 | 这面招牌已有的规则。点「新建规则」加一条新的 |
| 中间 积木画布 | 规则的积木都拼在这。可拖动平移、滚轮缩放 |
| 左侧 积木库 | 按类别分组，把积木拖到画布上用 |
| 右上 试跑 / 关闭 | 试跑会当场跑一遍，关闭退出编辑器 |
| 右侧 预览框 | 当前招牌的实时预览（可折叠 / 拖宽），用来点选元素、设目标坐标 |

改动**自动保存**，没有「保存」按钮。规则有没填完的地方会标提示，修好才会自动存。

## 拼一条规则

1. 左上点「新建规则」，会自带一顶橙色帽子。
2. 点帽子上的「什么时候触发」下拉，选触发方式（进服 / 定时 / 玩家靠近……，见下方触发器表）。
3. 从左边积木库拖一块动作到帽子下面，吸上去就接成一串。
4. 填好积木里的格子（选元素、填数值、选声音……）。
5. 想分情况处理就拖「如果」积木，往「那么 / 否则」里塞动作。
6. 改动自动保存，关掉编辑器，游戏里就生效了。

帽子下面接的积木，触发后**从上往下依次执行**。

![从积木库把动作拖到帽子下面拼成一串](/images/guide-scripting-02-palette.png)

## 触发器（帽子积木）

每条规则只有一顶帽子，它决定这条规则什么时候触发。共九种。

| 触发器 | 什么时候触发 | 要填 |
|---|---|---|
| 变量变化 | 你盯的某个变量一改值就触发 | 选一个变量 |
| 定时器 | 每隔 N 秒自动触发一次 | 间隔秒数（1~86400） |
| 招牌就绪 | 这面招牌在游戏里加载好的那一刻 | 无 |
| 玩家进服 | 任何玩家进入服务器时 | 无 |
| 玩家被击杀 | 一个玩家被另一个玩家击杀那一下（PvP；摔落、岩浆等环境死亡不算） | 无 |
| 玩家靠近 | 有玩家走进招牌周围 N 格范围（从外面进来那一下） | 范围格数（1~32） |
| 玩家离开范围 | 有玩家走出招牌周围 N 格范围（从里面出去那一下） | 范围格数（1~32） |
| 右键招牌 | 有玩家右键点这面招牌 | 无 |
| 玩家退服 | 任何玩家离开服务器时 | 无 |

::: warning 全服事件需要服主开权限
**玩家进服、玩家被击杀、右键招牌、玩家退服**这四种是「全服事件」（任意玩家都能触发），默认普通玩家用不了，要服主给 `canvas.script.trigger.global` 权限。其余五种普通玩家就能用。
:::

几个典型用法：

- **变量变化**——比分变了就刷新文字、插件推个「告警」就让招牌闪。
- **定时器**——每 5 秒滚动一次广告语、每分钟刷一次在线人数。
- **招牌就绪**——招牌一加载就摆好初始状态。
- **玩家进服 / 退服**——欢迎横幅、在线人数 ±1。
- **玩家靠近 / 离开范围**——走近时招牌「亮起来」（变大、显示细节），走远时「收起来」。
- **右键招牌**——把招牌当按钮：点一下切内容、播段动画、给点奖励。

## 动作积木

积木库按类别分组，颜色也对应分组。下面按类别介绍能干嘛。

### 元素动作

直接改招牌上的某个元素。每块先选哪个元素，再填目标值。

| 能干嘛 | 举例 |
|---|---|
| 移到 / 移动一点 | 把元素挪到指定坐标，或在当前位置相对偏移一段 |
| 改大小 / 旋转到 | 设宽高，或转到指定角度（0~359） |
| 变透明 / 显示 / 隐藏 | 设不透明度（0 全透明 ~ 1 不透明），或一键显示 / 隐藏 |
| 改文字 / 改颜色 | 改文字元素的内容（可带变量）或颜色（填 `#RRGGBB`） |
| 置顶 / 置底 | 把元素挪到本图层最上层（盖住别的）或最下层 |
| 克隆 / 删除 | 复制一个元素，或删掉一个元素 |

::: tip 不用手抄坐标
改坐标 / 大小时，点积木旁的靶心按钮，再去右侧预览框点一个元素，就会自动填好它当前的坐标 / 大小。也可以在预览框里直接拖元素的半透明虚影到想要的位置，积木会记下这个目标坐标。
:::

### 变量动作

改一个变量的值。

| 能干嘛 | 举例 |
|---|---|
| 设值 / 增减 | 直接设成某值，或加上 / 减去一个数（增量填负数就是减） |
| 乘除 / 随机 | 乘以 / 除以一个倍数，或随机一个 `最小`~`最大` 之间的数（做骰子、抽奖好用） |
| 取整 | 把变量当前数值四舍五入 / 向下 / 向上取整 |
| 复制 / 拼接 | 把一个变量的值复制到另一个，或在某变量末尾追加一段文字 |

填文字的格子都能写 `${var:X}`，执行时会替换成那个变量的当前值。

### 播放

| 能干嘛 | 举例 |
|---|---|
| 播放时间轴 | 控制一条时间轴动画：播放 / 暂停 / 跳到某个时刻 |
| 播放并等待 | 播一条时间轴，等它播完一轮再继续往下走 |
| 声音 | 给附近或全服玩家播一个音效（可调音量、音调，需服主开权限） |
| 粒子 | 在招牌位置播一簇粒子（14 种内置：火焰 / 爱心 / 烟花 / 暴击……可设数量和偏移，需服主开权限） |

先去时间轴编辑器排好动画，这里下拉就能选到它。声音和粒子默认要服主给 `canvas.script.sound` 权限。

### 玩家

| 能干嘛 | 举例 |
|---|---|
| 发消息 | 给触发的玩家或全服玩家在聊天框 / 动作栏 / 标题发一条文字 |
| 标题弹窗 | 给玩家弹一个屏幕中央大标题 + 副标题（可设淡入 / 停留 / 淡出时长） |

「发给」选「全服玩家」就是广播，选「触发的玩家」就只发给触发这条规则的人（比如刚进服 / 刚右键的那位）。文字里都能带 `${var:X}`。

### 高级

| 能干嘛 | 举例 |
|---|---|
| 执行命令 | 以服务器身份执行一条服主预设好的命令模板（见下方） |
| 写日志 | 往审计日志写一行字，调试用 |

「执行命令」是唯一能跳出招牌、影响整个服务器的积木，所以双重把关：服主要先在配置里写好命令模板（白名单），玩家还得有 `canvas.script.command` 权限（默认只有管理员）。服主没配任何模板时，这块积木会灰显。

### 等待

| 能干嘛 | 举例 |
|---|---|
| 等待 N 毫秒 | 停顿一段时间（50~5000 毫秒）再往下走 |
| 等待直到条件 | 卡在这里等到条件成立，或超时，才往下走 |

「等待」「等待直到」「播放并等待」这类积木会让脚本挂起——它不占线程死等，到点 / 条件满足了自动续上。

## 流程控制

| 积木 | 做什么 |
|---|---|
| 如果-否则 | 条件成立走「那么」，不成立走「否则」 |
| 随机分支 | 按一个百分比概率，随机走「那么」或「否则」（做随机事件） |
| 重复 N 次 | 把里面的积木重复执行固定次数（1~100） |
| 重复直到 | 反复执行里面的积木，直到条件成立（带「最多次数」安全阀，防转圈） |
| 在 X 秒内（补间） | 让元素在一段时间里平滑过渡到新位置 / 新大小 / 新颜色，而不是瞬间跳过去 |
| 停止脚本 | 立刻中止本条规则这一次的执行，后面的积木都不再跑 |

「如果」「随机分支」是 C 形积木，里面分「那么」「否则」两个槽。「重复 N 次」「重复直到」「在 X 秒内」也是 C 形，里面是循环体 / 过渡内容。

### 补间「在 X 秒内」怎么用

1. 拖一块「在 X 秒内」进规则。
2. 设时长（毫秒，如 `1500` = 1.5 秒）和缓动（匀速 / 由慢到快 / 由快到慢 / 两头慢中间快 / 自定义曲线）。
3. 往它**里面**拖元素动作（移到 / 改大小 / 旋转到 / 变透明 / 改颜色），选元素 + 目标值。
4. 可以放多个，会同时动（边移动边放大边变色）。

触发后元素在你设的时长内平滑过渡到目标，过渡完停在目标。脚本会等补间做完才走下一个动作。补间里只能放上述那五种属性动作，放别的（发消息等）会拖不进去——那些放在补间外面。

## 条件怎么写

「如果 / 等待直到 / 重复直到」都要写一个条件。可以用可视构建器一行行拼（比如「变量 `user/score` 大于 `10`」），也可以切到「高级（写表达式）」自己写。

取变量值用 `var("变量名")`。支持比较、且或非、四则算术：

```
var("user/score") > 0
var("user/team") == "red"
var("user/count") >= 10 && var("user/active") == "true"
var("user/score") - var("user/penalty") > 100
```

- 比较：`>` `<` `>=` `<=` `==` `!=`
- 逻辑：`&&`（且）`||`（或）`!`（非）
- 算术：`+` `-` `*` `/`

## 试跑：看脚本怎么走

排好规则，点右上角**试跑**，会当场跑一遍，积木按执行顺序逐个亮边框。

![试跑后积木逐个高亮，绿色表示执行到了](/images/guide-scripting-03-trace.png)

| 颜色 | 含义 |
|---|---|
| 绿色 | 这块正常执行到了 |
| 黄色 | 触发太频繁被拦下，或命令被安全规则拦下 |
| 红色 | 这块执行时报错（比如引用了不存在的元素、变量值不是数字） |

没点亮的积木就是这次没走到（比如「如果」走了「那么」，「否则」里的就不亮）。这是排查「为什么没生效」最快的办法。

![如果-否则只点亮走到的那一支](/images/guide-scripting-04-branch.png)

::: warning 试跑是真的执行
试跑不是模拟——它会真的发消息、真的执行命令、真的改招牌、真的播声音。别在高峰期试跑会广播或发奖励的规则。规则有没填完的地方时试跑会被挡住，先把提示的问题修好。
:::

## 几条上限

为了不让一条写错的规则拖垮服务器，脚本有几道安全阀。**别套太深、别太长**：

- **如果 / 随机分支别套太多层**：嵌套最多 4 层，第 5 层会被拒。
- **一条规则的积木别堆太多**：积木总数上限 50 块（包含嵌套里的）。
- **循环别转太多圈**：「重复 N 次」最多 100 次；「重复直到」也有最多次数上限，防止条件永远不成立时无限转圈。

碰到上限是保护机制，不是 bug。系统只掐断这一次，不会自动停用你的规则——你自己把规则改合理（循环次数调小、定时器间隔拉长）即可。这些上限服主可以在配置里调，但默认值对绝大多数场景够用。
