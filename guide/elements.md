# 元素与工具

招牌上的每样东西——文字、图形、图片、图标——都是一个**元素**。这一页带你认全 8 类元素、它们共通的属性，以及画图形用的工具。各元素独有的花样（文字特效、填充渐变、图片蒙版）有单独的页，这里只做总览加指路。

## 8 类元素

| 元素 | 是什么 |
|---|---|
| 文字 | 一段可排版的文本，能换字体、字号、颜色，加描边和阴影。 |
| 矩形 | 一个方块色块，可填充纯色或渐变，可加边框。 |
| 圆 / 椭圆 | 一个圆形或椭圆，把宽高拉得不一样就成椭圆。 |
| 多边形与星形 | 三角形、五边形、六角星之类，边数和内凹程度可调。 |
| 路径（线 / 箭头） | 用线段和曲线连成的图形，两端可加箭头或圆点。 |
| 笔刷 | 用鼠标或数位板手绘的笔迹，支持压感。 |
| 图片 | 你上传的 PNG/JPG 图，可旋转、调透明、套蒙版。 |
| 图标 | 内置图标库里的现成图标，几千个常用符号随挑随用。 |

## 所有元素都有的属性

不管哪种元素，选中后右侧面板顶部都有这几项：

| 属性 | 范围 | 说明 |
|---|---|---|
| 位置 x / y | −10000 ~ 10000 | 元素左上角在画布上的坐标，单位是像素。 |
| 大小 w / h | 1 ~ 10000 | 元素的宽和高（像素），不能小于 1。 |
| 旋转 | 0 ~ 359° | 顺时针旋转角度。 |
| 不透明度 | 0 ~ 100% | 0 是全透明、100 是完全不透明。 |
| 柔和过渡 | 开 / 关 | 让颜色和渐变在游戏里过渡得更顺，避免色块生硬。 |

「柔和过渡」开关在各元素自己的属性段里（比如图形段、笔刷段）。它的作用是用细密的混色让有限的地图颜色看起来更平滑，渐变和半透明区域尤其明显。

::: tip
直接在画布上拖动元素、拉边角、转旋转手柄，比手填数字更快。数字框适合微调到精确值。
:::

![元素通用属性面板](/images/guide-elements-02-transform-panel.png)

你可能注意到面板里还有一个**混色模式**下拉，它在元素这一级是灰的、点不动。混色要到**图层**那一级去设，详见[图层](/guide/layers)。

## 画图形的工具

左侧工具栏里有几把直接在画布上拖拽就能画出图形的工具：

| 工具 | 画出来是 |
|---|---|
| 直线 | 一条路径 |
| 箭头 | 一条带箭头的路径 |
| 圆 | 一个圆 / 椭圆 |
| 星形 | 一个星形 |

用法：

1. 点工具栏里的工具。
2. 在画布上按住鼠标拖出大小，松手即创建。
3. 拖的时候**按住 Shift**，能锁成正圆、正方、或 45° 的直线。

![用工具拖拽画图形](/images/guide-elements-03-draw-tools.png)

## 多边形与星形的参数

选中一个多边形或星形元素，在它的属性段里能调：

| 参数 | 范围 | 说明 |
|---|---|---|
| 形状 | 多边形 / 星形 | 在两种之间切换。 |
| 边数 | 3 ~ 32 | 3 是三角形，往上越多越接近圆。 |
| 内凹程度 | 仅星形 | 数值越小，星角越尖锐细长。 |

## 路径的端点标记

线和箭头本质都是路径。选中后可以给它的**起点**和**终点**各加一个标记：

- 箭头
- 圆点

两端可以分别设，比如一头箭头一头圆点。

## 笔刷

笔刷用来手绘自由笔迹：

| 参数 | 范围 | 说明 |
|---|---|---|
| 粗细 | 1 ~ 64 | 笔迹的基础宽度（像素）。 |
| 压感 | 开 / 关 | 用数位板或触控笔时，按得越用力线条越粗。 |

用鼠标画时压感取固定值，线条粗细均匀；接上数位板或用触控笔，开了压感后下笔轻重就能控制粗细。
