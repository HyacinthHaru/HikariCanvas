# 图片与图标

招牌上不只能放文字。你可以把自己的图片拖进画布、用蒙版裁成各种形状，也能从内置的两千多个图标里挑一个加进去。

## 上传图片

打开编辑器后，有三种方式把图片放进画布：

1. **直接拖**：把电脑里的图片文件拖到画布上，松手就上传。
2. **粘贴**：复制一张图片（或截图），在画布上按 Ctrl+V。粘贴一条图片网址也行，插件会自动下载。
3. **文件按钮**：点工具栏的上传图片按钮，从弹出的文件框里选一张。

支持 PNG、JPEG、WebP 三种格式。手机拍的照片如果是横竖颠倒的，上传后会自动转正。

::: tip
图片太大插件会自动缩小到合适尺寸，画面不会被一张巨图撑爆。
:::

## 大小和数量限制

下面是默认上限，服主可以在配置里改：

| 项目 | 默认上限 |
|---|---|
| 单张图片大小 | 2 MB（超过会被拒绝） |
| 单面招牌能放的图片数 | 16 张 |
| 每人每天能传的图片数 | 50 张 |
| 全服图片总容量 | 1 GB |

超过单张大小或当天次数，上传会失败并提示原因。全服容量满了，插件会自动清掉最久没人用的旧图腾出空间。

## 把图片裁成形状（蒙版）

选中一张图片，右侧面板里有「蒙版」一栏，能把图片裁成不同形状：

| 形状 | 效果 |
|---|---|
| 无 | 不裁，显示完整方图 |
| 圆 | 裁成正圆 |
| 圆角矩形 | 四角变圆 |
| 椭圆 | 按图片比例裁成椭圆 |
| 套索 | 自己在画布上画出任意形状来裁 |

两个额外开关：

- **反相**：把保留区和裁掉区对调——本来留中间，反相后变成留四周、挖空中间。
- **羽化**：让裁切边缘从实变虚，0 到 32，数字越大边缘越柔和。0 就是干脆的硬边。

不想要了，点「清除蒙版」恢复成完整方图。

## 图标库

除了图片，插件内置了两千多个 Font Awesome 图标，箭头、爱心、社交标志、各种小符号都有，直接拿来用，不用自己画。

点工具栏的图标按钮（或按 I 键）打开图标库面板。

![图标库面板](/images/guide-images-icons-02-icon-library.png)

面板里能做这些：

1. **按分类浏览**：顶部标签切换全部、实心、线框、品牌标志、自定义，还有你的收藏和最近用过的。
2. **搜索**：在搜索框输入英文关键词（如 `heart`、`star`、`arrow`），筛出对应图标。
3. **收藏**：鼠标移到图标右上角点星标，常用的图标存进收藏，下次直接在收藏分类里找。
4. **添加到画布**：单击图标会加到画布中央，也可以直接把图标拖到画布上你想放的位置。

图标加进来后是矢量的，放大不糊，还能在右侧面板里改填充颜色。
