# 到站屏：时刻表与铁路

用招牌做地铁、公交的到站屏：显示车次、终点站、还有几分钟到、是否进站。配好之后，招牌上的倒计时会自己跳，到点了自动滚到下一班。

这功能有两种用法，按你的规模选：

| 用法 | 适合 | 改一次影响 |
|---|---|---|
| 简单时刻表 | 一两块牌子，只需要"几点发车 + 终点" | 只这一面墙 |
| 完整铁路网络 | 整条线、很多站台屏要同步 | 所有绑这条线的墙一起更新 |

两种用法在招牌上的写法完全一样，区别只在后台怎么配。

## 用法一：简单时刻表（单面墙）

适合你只有一两块牌子，不想搭整套线路。直接给这面墙列几个发车时间和终点就行。

1. 在编辑器顶部点 **火车图标**，打开时刻表管理面板。
2. 一行一行加发车记录：填**发车时刻**（如 `08:30`）和**终点站**。
3. 想精确到秒，把"时间精度"切到 **秒**；只看分钟就保持 **分**。
4. 关掉面板。这面墙的到站变量立刻生效。

![时刻表管理面板：加发车时刻和终点](/images/guide-transit-01-schedule-manager.png)

配好后，在文字里写 `${var:schedule.next_departure}` 之类的占位符（下面有完整列表），招牌就会显示实时到站信息。

## 用法二：完整铁路网络（一处改全服同步）

适合整条线有很多站台屏。你定义一次"1 号线 + 各个站 + 车次 + 时刻表"，然后把每面墙绑到"哪条线、本站是哪站、哪个方向"。以后改时刻表，所有绑过的墙自动跟着变。

### 第一步：建线路、站点、车次

在编辑器顶部点 **铁轨图标**，打开铁路网络管理面板。从左到右一层层配：

1. **线路**：新建一条线，起个名字（如"1 号线"）和线路代号。
2. **站点**：选中线路，按顺序加站名，用上下箭头排顺序。
3. **车次**：给线路加车次，填这些信息：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 车次号 | 这班车的编号 | `A01` |
| 方向 | 上行 / 下行 | 上行 |
| 服务类型 | 见下表，4 种内置 + 自定义 | 大站快车 |
| 编组 | 几节车厢 | `6` |
| 区间 / 终点 | 这班车开到哪 | 郑州东 |
| 备注 | 想额外说明的 | 末班车 |

![铁路网络管理：线路、站点、车次](/images/guide-transit-02-rail-network.png)

服务类型有 4 种内置选项，也可以自己填字符串：

| 服务类型 | 含义 |
|---|---|
| 站站停 | 每站都停 |
| 大站快车 | 只停大站 |
| 区间车 | 只跑线路的一段 |
| 特快 | 停站最少、最快 |
| 自定义 | 选"自定义"自己填，如"通勤特急" |

### 第二步：填每站时刻表

给车次设置它在每一站的到达 / 发车时刻。可以自动生成（给首站时间 + 站间间隔 + 跳过哪些站），再逐站微调。跳站的车（如大站快车）那一站就不会停。

### 第三步：把墙绑到线路

回到这面墙，打开时刻表管理面板，展开"铁路绑定"，选三样：

1. **线路**——这块屏属于哪条线。
2. **本站**——这块屏装在哪个站台。
3. **方向**——显示上行还是下行的车。

绑定后，这面墙的到站变量就来自你刚配的时刻表，每站时刻精确读取，不是估算。改时刻表，所有绑这条线本站本方向的墙一起更新。

::: tip
绑了铁路网络后，原来用简单时刻表写的招牌文字一个字都不用改——变量名完全一样，数据来源自动切换。
:::

## 招牌上能显示哪些到站信息

不管你用哪种方式配，招牌文字里都用同一套占位符。写法是 `${var:schedule.变量名}`，插件会自动算出当前值并实时刷新。

下一班车：

| 占位符 | 含义 |
|---|---|
| `${var:schedule.next_departure}` | 发车时刻（`HH:mm` 或 `HH:mm:ss`） |
| `${var:schedule.next_arrival}` | 本站到达时刻 |
| `${var:schedule.next_destination}` | 终点 |
| `${var:schedule.next_terminus}` | 终点站（区间车显示区间终点） |
| `${var:schedule.eta_minutes}` | 还有几分钟 |
| `${var:schedule.eta_seconds}` | 还有几秒 |
| `${var:schedule.eta_mmss}` | 倒计时 `MM:SS`（如 `02:30`） |
| `${var:schedule.is_arriving}` | 是否进站（`true` / `false`） |
| `${var:schedule.arrival_status}` | 进站文案（进站中 / 空闲，文字可在配置里改） |

铁路网络专属（绑了线路才有值）：

| 占位符 | 含义 |
|---|---|
| `${var:schedule.next_run_number}` | 车次号（如 `A01`） |
| `${var:schedule.next_service_type_text}` | 服务类型文字（站站停 / 大站快车…） |
| `${var:schedule.next_cars}` | 编组节数 |
| `${var:schedule.next_notes}` | 备注 |

每个变量都有对应的"下一班"版本，把 `next_` 换成 `next2_` 即可，比如 `${var:schedule.next2_departure}` 是下一班的发车时刻。可以在屏上同时显示这班和下班。

::: tip
不用记这些名字。编辑文字时点变量按钮，或者打出 `${`，会弹出一个列表让你直接挑。
:::

## 时间精度：分还是秒

每面墙可单独选时间精度：

- **分**：倒计时按分钟跳，30 秒刷新一次，适合大部分公交 / 列车屏。
- **秒**：倒计时秒秒在跳，适合站台快到站的紧迫感。绑了铁路网络的墙固定用秒精度。

## 招牌文字示例

把占位符拼成一行真实的到站显示，比如：

```
${var:schedule.next_run_number} 次 → ${var:schedule.next_terminus}
${var:schedule.next_service_type_text} · ${var:schedule.next_cars} 节
还有 ${var:schedule.eta_mmss}  ${var:schedule.arrival_status}
```

招牌上会显示成类似这样（数据每秒自动刷新）：

```
A01 次 → 郑州东
大站快车 · 6 节
还有 02:30  进站中
```

![站台屏成品：车次、终点、倒计时](/images/guide-transit-03-departure-board.png)

只想做个简单公交屏的话，一行就够：

```
下一班 ${var:schedule.next_departure} 开往 ${var:schedule.next_destination}，还有 ${var:schedule.eta_minutes} 分钟
```
