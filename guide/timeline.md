# 时间轴动画

时间轴让招牌动起来：元素的位置、大小、旋转、不透明度、颜色、填充、文字都能随时间变化。配一段淡入淡出、来回飘动或滚动的字幕，几分钟就能搞定。

## 打开时间轴

在编辑器顶栏点**胶片**图标，画布下方会弹出一条时间轴面板。再点一次收起。

![编辑器顶栏的胶片图标与底部展开的时间轴面板](/images/guide-timeline-01-dock.png)

面板分两块：左边是元素和属性的轨道列表，右边是时间标尺和关键帧。顶上是一排播放控制和设置按钮。

如果还没有时间轴，点中间的**新建时间轴**按钮先建一条。

## 加关键帧：拉就设

做动画只要记住一句话：**把时间指针挪到某个时刻，再把元素调成那一刻该有的样子，插件就自动在这一刻记下一个关键帧。**

1. 点亮顶栏的**自动关键帧**开关（圆点图标，亮起时为红色）。
2. 在时间标尺上拖动红色时间指针，挪到你要的时刻。
3. 在画布上把元素拖到该在的位置、调好大小、颜色等。

这一刻就被记成一个关键帧。再挪到另一个时刻、再调一次，就有了第二个关键帧。两个关键帧之间的中间过程，插件会自动补出来——元素会平滑地从前一个样子过渡到后一个样子。

也可以手动加：把鼠标移到左侧某个元素那一行，点出现的**加关键帧**按钮，就在当前时刻给它记一帧。

![时间轴上一个元素的两个关键帧与红色时间指针](/images/guide-timeline-02-keyframes.png)

## 能做动画的属性

下面这些都能随时间变化：

| 属性 | 效果 |
|---|---|
| 位置 | 元素在画布上移动 |
| 大小 | 放大、缩小 |
| 旋转 | 转动 |
| 不透明度 | 淡入、淡出 |
| 颜色 | 文字或图形换色 |
| 填充 | 渐变、纯色填充变化 |
| 文字 | 到点切换显示的文字内容 |

位置、大小、旋转、不透明度这几项是连续平滑过渡；文字是到点直接切换（不会逐字渐变）。

在左侧元素行点开折叠箭头，能看到这个元素的每一条属性子轨道，单独管理某一项的关键帧。

## 缓动：让动作有快慢节奏

默认两帧之间是匀速过渡，看起来有点死板。**缓动**能让动作开头慢、结尾快，或者反过来，更自然。

选中一个关键帧后，点顶栏的**曲线**图标，打开缓动曲线编辑器。内置四种：

| 缓动 | 感觉 |
|---|---|
| 匀速 | 从头到尾一个速度 |
| 缓入 | 开头慢，越来越快 |
| 缓出 | 开头快，结尾慢下来 |
| 缓入缓出 | 两头慢、中间快，最自然 |

不够用还能自己调：拖动曲线上的两个控制点，捏出任意快慢节奏。曲线左右拖动有范围限制，上下可以拉出"冲过头再回弹"的效果。曲线怎么画，游戏里就怎么动，所见即所得。

![拖动控制点自定义缓动曲线](/images/guide-timeline-04-easing-custom.png)

## 循环方式

在设置（齿轮图标）里选这条时间轴怎么播：

| 方式 | 说明 |
|---|---|
| 播一次 | 从头放到尾就停 |
| 循环 | 放完从头再放，一直循环 |
| 来回往复 | 正着放一遍，再倒着放回来 |

## 什么时候开始播

同样在设置里，选触发方式：

| 触发 | 什么时候播 |
|---|---|
| 手动播放 | 你在编辑器里按播放才放 |
| 变量变化时 | 绑定的某个变量一变，就播一次 |
| 到点播 | 按设定的时间表自动播 |

选后两种时，会出现一个按钮让你挑要盯着哪个变量或哪张时间表。

::: tip
设成**循环**且**手动**触发的时间轴，会在有人看这面招牌时自动开始循环播放——关掉浏览器、重启服务器都不会停。
:::

## 实时预览

不用回游戏，在编辑器里拖动红色时间指针，画布就会实时显示动画在那一刻的样子。来回拖就能反复检查每一帧对不对。顶栏的播放按钮可以直接在编辑器里放一遍。

## 帧率

动画默认大约每秒 20 帧，够顺滑。服主可以在配置里调高上限，按服务器性能来定，插件不会自己偷偷降速。

## 配合积木脚本

积木脚本里有一块**播放时间轴**积木。把它接到"玩家靠近招牌""玩家进服"这类时机上，动画就会在那个时机自动播放，不用你手动按。这样能做出"有人走近才亮起来"的招牌。

怎么搭积木见[积木脚本](/guide/scripting)。
