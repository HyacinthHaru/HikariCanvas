# 动态数据：变量

普通招牌写死了就不变了。如果你想让招牌显示**会变的实时数据**——当前时间、在线人数、自己定的一个分数——就用变量。

变量就是一个会变的值。你把它写进文字里，招牌会自动跟着它一起变，不用回去手动改。

## 把变量放进文字

在文字里写占位符 `${var:变量名}`。招牌渲染时，这段占位符会被换成变量当前的值。

举例：文字写 `现在 ${var:system/server.time}`，招牌上就显示「现在 14:30」，并随时间走动自动更新。

三种放进去的方式，挑顺手的：

1. 直接在文字里敲 `${var:变量名}`。
2. 点编辑文字时的**插入变量**按钮，从列表里挑一个。
3. 在文字里输入 `${`，会自动弹出变量选择器。

![文字编辑框里的插入变量按钮和变量选择器](/images/guide-variables-01-picker.png)

放进去的变量会显示成一个**紫色胶囊**，而不是一长串字符。

- 鼠标**悬停**在胶囊上，能看到它当前的值和来源。
- **点击**胶囊可以改成绑定别的变量。
- 胶囊变**红色**说明这个变量找不到（被删了或名字写错），点一下可以一键补建。

![文字里的紫色变量胶囊](/images/guide-variables-02-chips.png)

## 四类数据源

变量按来源分四类。下面分别说明，重点看**写法**那一列。

### 用户变量（自己创建）

你自己在变量面板里创建的变量。打开编辑器右侧的**变量面板**，点新建，填名字、选类型，就有了。

类型只是给编辑器一个提示，决定改值时给你什么输入框，不限制实际能存什么：

| 类型 | 用途 |
|---|---|
| STRING | 任意文字 |
| NUMBER | 数字 |
| BOOLEAN | 开关（是 / 否） |
| COLOR | 颜色 |

用户变量分两种归属：

| 写法 | 说明 |
|---|---|
| `${var:user/变量名}` | 本墙专用。同名变量在不同招牌互不影响。 |
| `${var:userglobal/变量名}` | 全服共享。所有招牌看到同一个值，改一处全服跟着变（详见下文「全局变量」）。 |

![编辑器右侧的变量面板](/images/guide-variables-03-panel.png)

### 系统变量（插件自带）

插件启动就有，不用创建。全局系统变量写法要带 `system/`：

| 写法 | 显示内容 |
|---|---|
| `${var:system/server.time}` | 服务器本地时间（HH:mm） |
| `${var:system/server.real_time}` | 完整时间戳 |
| `${var:system/server.tick}` | 服务器 tick 计数 |
| `${var:system/server.online}` | 当前在线人数 |
| `${var:system/server.online_list}` | 在线玩家名（逗号分隔） |
| `${var:system/server.motd}` | 服务器 MOTD |
| `${var:system/server.tps}` | 服务器 TPS |
| `${var:system/server.name}` | 服务器名 |

还有几个跟「这面招牌自己」相关的变量，这几个可以**裸写**，不用带 `system/`：

| 写法 | 显示内容 |
|---|---|
| `${var:wall.id}` | 本招牌的编号 |
| `${var:wall.alias}` | 本招牌的别名 |
| `${var:wall.owner}` | 本招牌的作者名 |

### 记分板

直接读 Bukkit 记分板的分数。写法：

```
${var:scoreboard.目标名.玩家名}
```

例如记分板目标叫 `kills`、要看玩家 `Steve` 的分数，就写 `${var:scoreboard.kills.Steve}`。第一次用会有约十秒延迟把分数读上来，之后自动刷新。

### PlaceholderAPI

如果服务器装了 PlaceholderAPI，可以直接读它的占位符。两种写法：

```
${var:papi/%占位符%}
${var:papi.占位符}
```

例如读玩家名占位符 `%player_name%`，写 `${var:papi/%player_name%}`。

::: warning 别用冒号写法
PlaceholderAPI 变量**不能**写成 `${var:papi:%player_name%}`。用上面的斜杠 `/` 或点号 `.` 写法。
:::

## 找不到变量时显示什么

变量可能暂时没值、或者根本不存在。这时按下面的顺序兜底，直到拿到能显示的东西：

1. 你在占位符里写的备用文字 `${var:变量名|fallback=默认文字}`；
2. 变量自带的默认值；
3. 都没有，就显示 `???`。

所以想让招牌在变量缺值时也好看，就在占位符里加上 `|fallback=`。例如：

```
在线 ${var:system/server.online|fallback=统计中} 人
```

## 别名

变量名有时又长又难记。可以给它起个**别名**——一个好认的短名字。

别名只改**编辑器里的显示**：胶囊和列表会用别名展示，悬停时也能看到。它不改变量本身，占位符 `${var:...}` 里还是要写原来的变量名。

别名是**按招牌**记的，同一个变量在不同招牌可以起不同别名。在变量面板或变量选择器里，行末的铅笔按钮就能改别名。

![变量选择器里的别名、数值、变量名三列](/images/guide-variables-04-alias.png)

## 全局变量

普通用户变量（`user/X`）是本墙专用的，换一面招牌就是另一份。如果你想要一个**跨所有招牌共享**的值——比如全服通用的一个比分、一句公告——用全局变量 `userglobal/X`。

特点：

- 所有招牌看到同一个值，在任意一处改了，全服所有引用它的招牌一起变。
- 谁创建的就是谁的，别人能看、能引用，但默认改不了。
- 新建时在变量面板里把归属切到「全局」即可。

在变量面板里，全局变量单独列在一个区，标着创建者；不是你创建的会显示为只读。
