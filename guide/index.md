# 认识 HikariCanvas

HikariCanvas 让你在浏览器里像用设计软件那样做招牌，实时投影到 Minecraft 世界的墙上。

游戏内框出一面墙，浏览器里排版，改一下游戏里那面墙就跟着变——不用打指令拼字、不用堆方块。

![一面做好的招牌示例](/images/guide-index-01-showcase.png)

## 能做什么

由浅入深，每一项都不需要懂代码：

- 写一段**静态文字招牌**，挑字体、颜色、特效（描边、阴影、渐变）。
- 在上面加**图形、图片、图标**，自由排版、分图层。
- 让招牌显示**实时数据**：服务器时间、在线人数、记分板分数、地铁到站倒计时，还有你自己定义的变量。
- 给元素加**关键帧动画**，让文字淡入、图标移动、招牌循环播放。
- 用**积木脚本**让招牌跟玩家互动：玩家靠近、右键招牌、进服时触发动作。

## 整体流程

游戏里 `/canvas edit` 框墙 → 浏览器里排版 → 自动保存投影回游戏。一面招牌几分钟就能做完。

跟着 [做你的第一面招牌](/guide/making-a-sign) 走一遍最快上手。
