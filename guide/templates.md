# 模板

模板是别人事先做好的招牌布局——文字、图形、配色都排好了。套到你的墙上，几秒钟就有一面像样的招牌，不用从空白开始。

你也能反过来，把自己做好的招牌存成模板，给别人套用。

## 套用一个模板

1. 在编辑器里打开**模板库**（顶部工具栏的模板按钮）。
2. 左边是模板列表，点一个，右边会显示它的说明、适用的墙面尺寸，以及可以改的文字。
3. 改右边那些可填的内容（比如店名、标语），这些是模板作者留给你填的空。
4. 点**应用**。

![模板库：左边列表，右边参数](/images/guide-templates-01-gallery.png)

::: warning 应用会覆盖整面画布
套用模板会**替换当前招牌的全部内容**。如果墙上已经有东西，会先弹一次确认。想保留旧的，先做好备份或换一面墙。
:::

列表里某个模板名字旁边有红色感叹号，说明它的设计尺寸和你这面墙对不上。强行套用会显示不全，先换一个尺寸合适的模板，或换一面墙。

## 把当前招牌存为模板

做好一面满意的招牌，可以存成模板重复使用，或分享出去。

1. 在编辑器里打开**存为模板**对话框。
2. 填三样东西：

| 填什么 | 说明 |
|---|---|
| 标识名 | 模板的内部短名，只能用小写字母、数字和连字符，比如 `shop-sign` |
| 显示名称 | 别人在模板库里看到的名字 |
| 简介 | 一句话说明这模板是干嘛的（可不填） |

![存为模板对话框](/images/guide-templates-02-save-modal.png)

### 选哪些文字可以改

招牌里的每段文字，对话框都会列出来，让你逐条决定：

- **设为可填**——别人套用时能把这段字改成自己的（比如店名、价格）。设为可填后还能给它起个名字、写个提示，告诉对方该填什么。
- **保持原样**——这段字固定写死，套用的人改不了（比如统一的落款、装饰文字）。

逐条选完，点保存。模板就进了模板库，之后你（和被授权的人）都能套用。

![逐条选择文字是否可填](/images/guide-templates-03-params.png)

## 模板从哪来

模板库里的模板有几个来源：

| 来源 | 说明 |
|---|---|
| 内置 | 插件自带的基础模板 |
| 服务器 | 服主在本服添加的模板 |
| 玩家发布 | 你和其他玩家自己存出来的模板 |

带**精选**标记的是被挑出来推荐的模板，通常质量更高，可以优先看。

## 谁能用谁的模板

| 模板 | 谁能用 |
|---|---|
| 内置、服务器模板 | 所有人 |
| 你自己发布的模板 | 你自己 |
| 别人发布的模板 | 默认用不了，需要服主额外授权 |

简单说，内置和服务器模板对所有人开放；玩家发布的模板默认只有作者本人能套用。想让大家互相套用彼此的模板，得让服主开通对应权限。

## 能发布多少个

每位玩家默认最多发布 **20 个**模板。到上限后想再发，先删掉一些旧的。这个数量服主可以调整，具体上限问你所在服务器的管理员。
