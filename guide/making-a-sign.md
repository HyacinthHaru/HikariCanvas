# 做你的第一面招牌

跟着这一页走一遍，你就能在游戏里做出第一面招牌：从拿工具、框墙面，到在浏览器里排版、保存。全程几分钟。

## 开始前

你需要：

- 一面**竖直的实心墙**（朝东、南、西、北任意一面都行），墙的正前方留出空格。
- `canvas.edit` 权限（默认所有玩家都有）。

## 第一步：拿到画布魔杖

在游戏里输入：

```
/canvas edit
```

背包里会出现一把名为 **Canvas Wand** 的金铲子，它是框选墙面的工具。

![手持画布魔杖](/images/guide-making-a-sign-01-wand.png)

## 第二步：框出墙面

对着要做招牌的墙，点两个对角：

1. **左键**点左上角的方块——第一个角。
2. **右键**点右下角的方块——第二个角。

每点一次，聊天栏会显示当前框选的范围（几格宽、几格高、朝哪个方向）。两个角要在同一面竖直墙上。

![框选墙面两角，聊天栏显示范围](/images/guide-making-a-sign-02-select.png)

::: tip
一格 = 一张地图 = 128×128 像素。框 2×1 就是两格宽、一格高的招牌。
:::

如果聊天栏提示框选失败，对照下表：

| 提示 | 原因 |
|---|---|
| 只能框竖直墙面 | 点到了地面或天花板 |
| 方块不是实心 | 墙体里有玻璃、台阶、草等不完整方块 |
| 前方被挡住 | 墙正前方那一格不是空气 |
| 已被占用 | 那块墙已经有别人的招牌 |

## 第三步：确认并打开编辑器

范围满意后，输入：

```
/canvas confirm
```

插件会在墙上挂好画框，并在聊天栏给你一条编辑器链接。点它，浏览器就会打开编辑器。

![确认后聊天栏里的编辑器链接](/images/guide-making-a-sign-03-confirm-link.png)

::: warning 链接是一次性的
这条链接**只对你有效、只能用一次、15 分钟内有效**。超时或用过之后，用 `/canvas open`（见最后一节）重新获取。
:::

## 第四步：加一段文字

编辑器打开后是一块空画布。

1. 点左侧的**加文本**按钮，画布中央会出现一个文字块。
2. **双击**文字块，改成你想写的内容。
3. 在右侧面板调字体、字号、颜色。

你改的每一下都会**自动保存并实时投影到游戏里**——不用点保存按钮，回游戏看那面墙就能看到变化。

![编辑器里加好的一段文字](/images/guide-making-a-sign-04-editor.png)

## 第五步：锁定（可选）

做完想防止自己手滑改动，点编辑器顶部的**锁**按钮，招牌就变成只读。只有你（作者）能再把它解锁。

![编辑器顶部的锁按钮](/images/guide-making-a-sign-05-lock.png)

## 之后怎么再编辑、删除

每面招牌都有一个像 `w-1a2b3c4d` 这样的编号，`/canvas list` 能查到。

| 想做的事 | 怎么做 |
|---|---|
| 再次编辑 | `/canvas open <编号或别名>`，或拿魔杖对着招牌连点两下 |
| 给招牌起个好记的别名 | `/canvas alias <别名>` |
| 查看自己的所有招牌 | `/canvas list` |
| 删除招牌 | 先 `/canvas delete <编号>`，再在 30 秒内 `/canvas delete <编号> confirm` |
