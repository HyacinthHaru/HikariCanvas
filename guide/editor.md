# 编辑器导览

打开编辑器后你看到的是一块画布加四周的面板。这一页带你认全每个区域、每把工具和常用快捷键。

![编辑器全貌](/images/guide-editor-01-overview.png)

## 界面分区

| 区域 | 位置 | 作用 |
|---|---|---|
| 工具栏 | 最左侧竖排 | 选工具、撤销重做、加文本/矩形、打开图标库和模板库 |
| 画布 | 正中间 | 你的招牌，所见即所得，改动实时投影到游戏里 |
| 属性面板 | 右侧 | 调当前选中元素的字体、颜色、大小等参数 |
| 顶栏 | 最上方 | 锁定按钮、别名、变量/时刻表等管理入口 |
| 图层面板 | 右侧 | 管理图层的显示、锁定、上下叠放顺序 |
| 缩放条 | 画布右下角 | 缩放、适配视口、上传图片、设网格大小 |

## 工具栏

每把工具都有快捷键，鼠标悬停按钮也能看到。

| 工具 | 快捷键 | 作用 |
|---|---|---|
| 选择 | V | 点选元素，拖动手柄改大小、旋转 |
| 移动 | M | 点中即拖，不显示缩放手柄，适合挪大元素 |
| 抓手 | H | 拖动平移整块画布视图 |
| 直线 | L | 拖出一条直线 |
| 箭头 | A | 拖出一个箭头 |
| 圆 | C | 拖出一个圆或椭圆 |
| 星形 | S | 拖出一个星形 |
| 笔刷 | B | 手绘自由线条 |
| 油漆桶 | G | 点空白区域填色，或点元素内部直接改它的颜色 |

工具栏底部还有几个按钮：

- **图标库**（快捷键 I）：打开内置图标面板，拖图标进画布。
- **加文本**：在画布中央放一个文字块。
- **加矩形**：在画布中央放一个矩形。
- **模板库**、**撤销**（Ctrl+Z）、**重做**（Ctrl+Shift+Z）。

### 拖拽创建图形

直线、箭头、圆、星形、矩形这类图形都是**在画布上按住拖出来**的：按下定起点，拖到合适大小松手。

按住 **Shift** 拖拽会锁等比：圆变正圆、矩形和星形变正方形、直线和箭头锁到 0°/45°/90° 这些角度。

## 缩放与平移

画布可以放大到 400%、缩小到 25%。

| 想做的事 | 怎么做 |
|---|---|
| 放大 / 缩小 | 缩放条的 + / − 按钮，或 Ctrl/⌘ + = / Ctrl/⌘ + − |
| 以光标为中心缩放 | 按住 Ctrl/⌘ 滚动鼠标滚轮 |
| 复位到 100% | Ctrl/⌘ + 0，或缩放条的复位按钮 |
| 自动适配视口 | 缩放条的适配按钮，画布自动缩到刚好放满 |
| 直接输入倍数 | 点缩放条中间的百分比数字，填一个 25–400 的值 |

平移视图（不改内容，只挪视角）有三种方式，挑顺手的：

- 选**抓手**工具后直接拖。
- 在任意工具下**按住 Space** 临时切成抓手，松开恢复原工具。
- **按住鼠标中键**拖，或 **Alt + 左键**拖。

## 常用快捷键

在画布上（不是在输入框里）按这些键：

| 快捷键 | 作用 |
|---|---|
| Ctrl/⌘ + C | 复制选中元素 |
| Ctrl/⌘ + V | 粘贴，可跨招牌粘贴 |
| Delete / Backspace | 删除选中元素 |
| Ctrl/⌘ + Z | 撤销 |
| Ctrl/⌘ + Shift + Z 或 Ctrl/⌘ + Y | 重做 |
| Ctrl/⌘ + A | 全选当前图层所有元素 |
| 方向键 | 把选中元素微移 1 像素 |
| Shift + 方向键 | 微移 10 像素 |

::: tip
复制粘贴跨招牌有效：在一面招牌上 Ctrl+C，到另一面招牌上 Ctrl+V 就能搬过去。
:::

## 智能吸附

拖动元素时，它会自动对齐到这些参考线，帮你摆整齐：

- 画布的边和中线
- 其它元素的边和中线
- 网格线
- 等距分布（让三个元素间距相等）

命中时画布上会闪出红线或绿色间距标注。如果某次想随手放、不要吸附，**拖动时按住 Shift** 临时关掉它。吸附的开关和参考类型可以在缩放条旁的磁铁按钮里调。

## 对齐与分布工具条

同时选中 **2 个或以上**元素时，画布顶部中间会冒出一条工具条。

![选中多个元素后出现的对齐分布工具条](/images/guide-editor-02-align-bar.png)

| 按钮 | 作用 |
|---|---|
| 左 / 水平居中 / 右 | 把选中元素左边、中线、右边对齐 |
| 上 / 垂直居中 / 下 | 把选中元素顶边、中线、底边对齐 |
| 水平分布 | 让元素之间横向间距相等 |
| 垂直分布 | 让元素之间纵向间距相等 |

分布按钮需要至少选中 3 个元素才能用。

![对齐前后对比](/images/guide-editor-03-align-result.png)

## 网格

想按格子摆元素，在缩放条最右边的**网格**输入框里填一个像素值（填 0 关闭）。开了网格再配合智能吸附里的「对齐网格」，拖动时就会自动贴到格线上。
