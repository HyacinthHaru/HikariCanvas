# 图层

图层就像一摞透明胶片，每张上面画一些东西，叠起来组成最终画面。把文字、图片、图形分到不同图层，调整起来互不干扰，做复杂招牌时会省心很多。

图层面板在编辑器侧边，列出当前招牌的所有图层。

::: tip
列表**最上面那层 = 画面最上层**，会盖住下面的图层。想让某个元素显示在最前，就把它的图层往上拖。
:::

![图层面板](/images/guide-layers-01-panel.png)

## 新建、复制、删除

| 想做的事 | 怎么做 |
|---|---|
| 新建图层 | 点面板顶部的加号，新层叠在当前活动图层之上 |
| 复制图层 | 鼠标移到图层上，点复制按钮，连同里面的元素一起复制一份 |
| 删除图层 | 鼠标移到图层上，点垃圾桶按钮 |
| 重命名 | 双击图层名字，输入新名字后回车 |

至少要保留一个图层，所以**最后一层删不掉**，删除按钮会变灰。

## 活动图层

每次只有一个图层是「活动」的，列表里高亮的那个就是。新加的文字、图片、图标都会落到活动图层上。想往哪层加东西，先点一下那层把它选成活动图层。

## 显示、隐藏、锁定

每个图层左边有两个小按钮：

- **眼睛**：点一下隐藏这层，再点恢复。隐藏的图层不显示在招牌上，但内容还在。
- **锁**：锁住这层后，里面的元素不能被选中或移动，防止手滑改动。

## 不透明度和混色模式

选中活动图层时，下方会展开两个控件，只对这个图层生效：

- **不透明度**：拖滑块让整层变半透明，0% 全透明、100% 不透明。
- **混色模式**：决定这层颜色怎么和下面叠加。普通是直接盖住；正片叠底偏暗、滤色偏亮、叠加增强对比。不确定就用普通。

![活动图层的不透明度和混色控件](/images/guide-layers-02-blend.png)

## 颜色标签

图层多了容易分不清。给图层标个颜色，列表左边会显示一道彩色条，一眼就能认出来。

一共 7 种颜色：红、橙、黄、绿、蓝、紫、灰。点一个色点上色，再点一次同色取消，点叉号清除。这只是给你自己看的标记，不影响招牌画面。

## 顺序、缩略图和元素数量

- **拖动排序**：按住图层上下拖，改变叠放顺序。越靠上越显示在前。
- **缩略图**：每层左侧有张小预览图，显示这层画了什么。
- **元素数量**：图层名右边的数字是这层里有几个元素。
