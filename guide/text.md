# 文字

招牌上最常放的就是文字。选好字体、调好大小和颜色，再加点描边阴影，一段普通文字也能很出彩。这一页讲编辑器右侧面板里文字的全部选项。

加文字的方法见 [做你的第一面招牌](/guide/making-a-sign)：点左侧**加文本**，双击改内容，右侧面板调参数。

## 选字体

字体下拉里分两组：

- **内置字体**：插件自带，下面这张表全列出来了。
- **用户字体**：服主自己放进字体文件夹里的字体。你的服务器有没有、有哪些，取决于服主。

插件自带 22 枚字体，按风格分这几类。

**中文正文**

| fontId | 名字 | 风格 |
|---|---|---|
| `source_han_sans` | 思源黑体 | 标准黑体，最百搭 |
| `source_han_serif` | 思源宋体 | 衬线宋体，正式 |
| `ark_pixel` | Ark Pixel | 12px 像素字，复古 |

## 字号、间距、行高、对齐

| 选项 | 范围 | 说明 |
|---|---|---|
| 字号 | 1 ~ 512 | 文字大小（像素） |
| 字间距 | −32 ~ 128 | 字与字的间隔；负数让字挤得更紧 |
| 行高 | 0.5 ~ 4.0 | 行与行的间隔倍数，默认 1.2 |
| 对齐 | 左 / 中 / 右 | 多行文字每一行各自对齐 |

## 加粗、斜体、竖排

- **加粗**：点 **B** 按钮，文字变粗。
- **斜体**：点 **I** 按钮，文字向右倾斜。
- **竖排**：勾上"竖排"，文字从上往下排——适合做对联、店招这类竖牌子。

## 文字特效

在"特效"段里可以给文字叠描边、阴影、发光，三个能同时开。

**描边**：给文字加一圈边框，让它在花哨背景上更清楚。

| 选项 | 范围 |
|---|---|
| 粗细 | 0 ~ 128 |
| 颜色 | 单色 |

**阴影**：在文字后面投一层错位的影子，立体感更强。

| 选项 | 范围 |
|---|---|
| 水平偏移 | −128 ~ 128 |
| 垂直偏移 | −128 ~ 128 |
| 颜色 | 单色 |

**发光**：让文字边缘晕开一圈光，霓虹招牌就靠它。

| 选项 | 范围 |
|---|---|
| 半径 | 0 ~ 64 |
| 颜色 | 单色 |

![开了描边和发光的文字](/images/guide-text-02-effects.png)

## 几个限制

- 文字颜色，以及描边、阴影、发光的颜色，都是**单色**（`#RRGGBB` 这样的十六进制），不支持渐变。想要渐变只能用图形元素，见 [填充、颜色与透明](/guide/fill)。
- 一段文字最多 **256 个字**。要写更长的内容，拆成几段分开放。
