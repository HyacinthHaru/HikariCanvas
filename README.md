## 欢迎使用 HikariCanvas

> 一个 Minecraft 里的 Canva / Figma 编辑器
> 
> 目前还在开发中，ETA 2026.06 月末

未来将变成一个实时在游戏内更新的地图画编辑系统，且支持模板、自定义字体、画笔、上传图片、动态数据等功能。

哦对了，还会支持变量系统、列车时刻表、动画编辑甚至是 Scratch-like 的可视化脚本执行编辑功能。

最终目标是做成 Minecraft 内的视觉运行时，让 MC 里能有视觉动画效果、写视觉脚本、做列车 PIDS（）

这个项目的部分内容使用了 AI 进行编写代码，但全程遵循本人的技术准绳，且定期进行回顾和集中 Debug。

感谢你的关注！
