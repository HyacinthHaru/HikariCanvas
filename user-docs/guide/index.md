# 认识 HikariCanvas

HikariCanvas 是一个 Minecraft Paper 1.21+ 插件，它在服务器里内嵌了一个浏览器编辑器。你用游戏内的魔杖在墙面上框出一块区域，再到浏览器里像用设计软件那样排版文字、图形、图片，编辑器会把成品实时投影到游戏世界的告示墙上。

## 它能做什么

- 在墙上做**文字招牌**：多种字体、颜色、渐变、特效。
- 显示**实时信息**：时间、在线人数、记分板、地铁到站倒计时、自定义变量。
- 做**动画**：时间轴关键帧 + 补间动画。
- 写**互动脚本**：玩家靠近、右键、进服等事件触发积木逻辑。

## 快速上手三步

1. 拿魔杖：`/canvas edit`
2. 左键、右键点墙上画框阵列的两个对角，再 `/canvas confirm`
3. 点聊天栏里的链接，打开浏览器编辑器开始画
