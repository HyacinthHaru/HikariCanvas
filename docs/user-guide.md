# HikariCanvas 玩家与服主使用手册

这篇手册面向日常使用插件的**玩家**与管理服务器的**服主**，涵盖游戏内建墙管理、网页编辑器常用工具、`/canvas` 全命令速查、LuckPerms 权限配置方案，以及自定义字体和模板的投放方法。

如果你已经熟悉基础操作，想探索动态数据、动画或交互逻辑，可以直接阅读对应的进阶指南：
- [变量与铁路教程](variables.md) —— 动态数字、PlaceholderAPI 接入、列车时刻表与全线铁路网络
- [时间轴动画指南](timeline-guide.md) —— 关键帧与缓动曲线动画
- [积木脚本指南](scripting-guide.md) —— 玩家右键、靠近等触发的积木逻辑与补间过渡

## 第一部分：游戏内建墙与日常管理

### 1.1 创建第一块招牌

1. **进入选区模式**：在游戏内输入 `/canvas edit`。如果背包里还没有选区工具，系统会自动发给你一把 **Canvas 魔棒**（金铲）。
2. **点选墙面对角**：对准同一面平整墙体，**左键**点击第一个角，**右键**点击对角方块。屏幕会提示当前选区的宽高（以地图张数计）与朝向。
   - 如果选错了位置，重新左键/右键点选，或者再输一次 `/canvas edit` 即可重置选区；中途不想建了输入 `/canvas cancel` 退出并回收魔棒。
3. **确认并打开网页**：输入 `/canvas confirm`。插件会在墙面上自动铺好展示框与地图，并在聊天栏发出一行可点击的编辑器链接。
4. **浏览器作画**：点开链接进入网页编辑器，你在画布上的每一次改动都会自动保存，并实时同步到游戏里的墙面上。

> 聊天栏弹出的编辑链接带有一次性访问令牌，有效期 **15 分钟**，被第一个打开它的浏览器绑定后即失效。如果链接过期或不小心关掉了网页，随时按下面的方法重新打开即可，墙上的画不会丢。

### 1.2 重新打开已有的招牌

想修改以前做好的招牌，有两种顺手的方式：

- **命令打开**：输入 `/canvas list` 查看自己名下的所有画板（点击列表条目可直接补全命令），然后输入 `/canvas open <画板ID或别名>` 拿到新的编辑链接。
- **魔棒直接点墙**：手里拿着 Canvas 魔棒（没有的话输 `/canvas wand` 领一把），对准游戏里已有的招牌点一下，动作栏会显示这块画板的编号；**30 秒内再点一次**，聊天栏就会直接弹出它的编辑链接。

同一时刻一块画板只能由一个人打开编辑。如果同伴正在画，你会收到「该画布正在被某某编辑」的提示；等你自己改完想提前释放会话时，也可以在游戏里输入 `/canvas cancel`（画板内容和展示框都会完好保留）。

### 1.3 起别名、锁定防误改与刷新修复

- **给画板起别名**：系统分配的默认编号形如 `w-3a17b2c0`，不太好记。打开画板会话后，在游戏里输入 `/canvas alias <别名>`，或者直接点击网页编辑器左上角的画板名称，就能设一个好记的英文别名（2–32 位字母、数字、`_` 或 `-`，全服唯一）。设好后直接用 `/canvas open shop_sign` 就能打开。
- **草稿协作与作者锁定**：
  - 新建的画板默认处于**可编辑**状态——任何有基础编辑权限的玩家拿到编号都能打开接力排版，适合多人合建。
  - 定稿后不想被别人误改，点击网页编辑器顶栏的 **锁定** 按钮即可把画板设为只读。锁定后只有你（画板创建者）能解锁，其他玩家即使打开也只能查看、无法改动。
- **缺块或缺框一键修复**：如果招牌背后的方块或展示框被管理员意外拆掉，打开网页编辑器点击顶栏的 **刷新画板** 按钮，插件会自动补齐缺失的支撑方块、重新挂回展示框并强制重绘一次。

### 1.4 删除招牌

删除采用 **30 秒二次确认**，防止输错编号误删作品：

```text
/canvas delete <画板ID>
/canvas delete <画板ID> confirm
```

确认后，游戏世界里对应的展示框会被一并清理，占用的地图也会归还到服务器地图池中。注意：删除时画板所在的世界必须处于已加载状态。

## 第二部分：网页编辑器导览

网页编辑器分为四块区域：**顶栏**（画板状态、撤销重做、动态功能与导入导出）、**左侧工具栏**、**中央画布**和**右侧属性与图层面板**。顶栏右侧可以随时切换深浅色主题、中英文界面，以及查看完整的快捷键提示。

### 2.1 画布视野与图层管理

- **平移与缩放**：鼠标滚轮缩放画布；按住 **空格键**（或按 `H` 切换到手型工具）拖动即可平移视野。
- **选择与移动**：选择工具（`V`）点击元素可拖动、缩放或旋转；移动工具（`M`）隐藏缩放手柄，适合在密集排版里微调位置而不误拉尺寸，双击文字依然可以直接改字。
- **智能对齐吸附**：拖动或缩放元素时，画布边缘、中心线、网格以及其他元素的边缘与间距会自动吸附对齐；拖到一半按住 `Shift` 可临时跳过吸附做自由微调。
- **多图层**：右侧图层面板支持新建、重命名、隐藏、锁定图层、调整上下叠放顺序与混合模式，做复杂背景板时可以把底图图层锁住再排前景文字。

### 2.2 文字、图形与油漆桶

- **文字排版**：内置 **22 款开源字体**，覆盖中文黑体、宋体、12px 像素体、毛笔楷书、文楷与多款站酷艺术字，以及西文衬线、等宽、手写和美式路牌字体。支持加粗、斜体、描边、阴影、外发光与渐变字色，网页里看到的字距换行与游戏内地图严格一致。
- **基础图形与笔刷**：提供矩形、圆 / 椭圆（`C`）、五角星（`S`）、直线（`L`）、箭头（`A`），填充色支持纯色、线性渐变与径向渐变（背景同样支持渐变或透明）；笔刷工具（`B`）支持自由手绘及数位板 / Apple Pencil 压感。
- **矢量图标库（`I`）**：内置完整的 Font Awesome 矢量图标库，搜英文关键词即可点击或拖入画布，自由改色缩放不糊边。
- **油漆桶（`G`）**：点击已有图形内部可直接替换填充色；点击由多条路径或形状围出来的闭合空白区域，会自动识别轮廓并生成一块严丝合缝的填色区域。

### 2.3 图片上传、蒙版裁剪与 SVG 导入

- **上传图片**：支持直接在画布上 `Ctrl+V` / `Cmd+V` 粘贴截图、拖拽本地 **PNG / JPEG** 文件上传，或填入公网图片直链。插件会自动用 248 色地图调色板与抖动算法还原色彩。
- **路径蒙版**：选中图片后可在右侧属性面板添加裁剪蒙版（支持正选或反选裁剪），把方形图片裁成圆角、圆形或任意自定义轮廓。
- **导入 SVG 矢量图**：点击顶栏「更多（`…`）→ 导入 SVG」，可把外部设计软件导出的静态 `.svg` 图标或徽标解析成画布内的可编辑矢量路径（注意去掉 SVG 里的外部位图或复杂滤镜，节点越精简效果越好）。

### 2.4 工程备份（`.canvas`）与模板工坊

- **导出与导入 `.canvas` 工程**：点击顶栏「更多 → 导出工程」，当前画板的所有图层、上传的图片、时间轴动画和积木脚本会被完整打包成一个 `.canvas` 文件下载到本地。换服务器或给朋友分享时，在目标画板里选「导入工程」即可一键还原（若目标服缺少某款自定义字体或命令模板，编辑器会弹窗说明并自动降级处理，不会损坏画面）。
- **服内模板库**：做好一套满意的店铺招牌或站牌后，点顶栏「更多 → 存为模板」，可以把里面的店名、颜色、字号勾选为「可填参数」发布到模板库。下次新建画板时，点左侧工具栏的**模板库**图标，填几个字就能直接套用整套版式。

## 第三部分：`/canvas` 命令速查

### 3.1 玩家日常命令

| 命令 | 默认权限 | 用途 |
| --- | --- | --- |
| `/canvas edit` | 全员可用（`canvas.edit`） | 进入选区模式并自动领取魔棒（仅限游戏内玩家执行） |
| `/canvas wand` | 全员可用（`canvas.wand`） | 单独领取一把 Canvas 魔棒（背包已有时不会重复发放） |
| `/canvas confirm` | 全员可用（`canvas.edit`） | 确认当前选区，生成或绑定展示框并获取网页编辑链接 |
| `/canvas cancel` | 全员可用（`canvas.edit`） | 取消当前选区或结束编辑会话（不删画板数据） |
| `/canvas open <ID或别名>` | 全员可用（`canvas.edit`） | 直接打开一块已有画板并获取新的编辑链接 |
| `/canvas list` | 全员可用（`canvas.edit`） | 列出自己创建的全部画板（管理员执行时列出全服画板） |
| `/canvas alias <别名>` | 全员可用（`canvas.edit`） | 为当前正在编辑的画板设置全服唯一别名 |
| `/canvas delete <ID> [confirm]` | 全员可用（`canvas.delete.own`） | 删除自己的画板（需在 30 秒内带 `confirm` 二次确认） |

### 3.2 服主管理与诊断命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/canvas stats` | `canvas.admin`（默认 OP） | 查看地图池余量、画板总数、活跃编辑会话、变量与动画概况 |
| `/canvas diagnose <画板ID>` | `canvas.admin`（默认 OP） | 逐项检查某块画板的地图分配、所在世界加载状态、工程数据与动画状态 |
| `/canvas reload config` | `canvas.admin`（默认 OP） | 热重载 `config.yml` 中标记为 `[热更]` 的配置项及 `lang/` 语言文件 |
| `/canvas reload templates` | `canvas.admin`（默认 OP） | 重新扫描 `templates/` 目录下的预设模板并刷新缩略图缓存 |
| `/canvas var <子命令>` | `canvas.var.command`（默认 OP） | 查看、修改、删除变量或重载推送限流（详见 [变量教程 §2.1](variables.md)） |
| `/canvas bench <子命令>` | `canvas.bench`（默认 OP） | 在后台运行渲染、补间与脚本性能压测并生成报告（详见 [性能压测指南](benchmark.md)） |

> 服主不进游戏也可以直接在**服务端控制台**执行 `canvas open / list / alias / delete / cancel` 来查看、编辑或清理全服任意画板（详见 [部署指南 §6.1](deployment.md)）。

## 第四部分：服主权限配置指南

HikariCanvas 的默认权限策略非常省心：**装上插件不改任何权限即可正常游玩**——普通建墙、传图、设变量、排时刻表与基础脚本默认对全体玩家开放；删他人作品、绕过锁定、超配额、执行控制台命令模板和运维诊断默认仅限 OP。

同时，插件在选区阶段会自动尊重 **WorldGuard、GriefPrevention、Residence** 等领地与保护插件的方块交互拦截——玩家无法在自己没建筑权限的领地里用魔棒圈墙；建好的招牌展示框与背后的支撑方块也会自动受保护，不会被路人打掉。

### 4.1 三种常见服型的 LuckPerms 抄作业方案

#### 方案 A：休闲生存 / 创造服（允许玩家互用工坊模板）
默认配置下，玩家发布到模板工坊的个人模板仅自己和管理员可见。如果你希望服内玩家可以互相浏览、套用彼此分享的模板，补一条权限即可：

```text
/lp group default permission set canvas.template.use-others true
```

#### 方案 B：人多的公网大服（收紧全服打扰类积木）
如果担心熊孩子在积木脚本里滥用全服聊天广播、高频播放音效或监听全服进服事件，可以把这三项从默认组收掉，只留给信任玩家或建筑组：

```text
/lp group default permission set canvas.script.broadcast false
/lp group default permission set canvas.script.sound false
/lp group default permission set canvas.script.trigger.global false
```

#### 方案 C：仅限建筑师或赞助组使用插件
`canvas.use` 是整棵 `/canvas` 命令树的总开关。把它从默认组关掉、单独赋给目标权限组，未授权玩家连命令补全都不会看到：

```text
/lp group default permission set canvas.use false
/lp group builder permission set canvas.use true
```

## 第五部分：添加自定义字体、图标与公共模板

服主可以往 `plugins/HikariCanvas/` 下的对应文件夹放入扩展资源，所有资源都由服务端统一分发给网页编辑器，**玩家客户端不需要安装任何字体或材质包**。

### 5.1 添加自定义字体（`plugins/HikariCanvas/fonts/`）

内置的 22 款字体已经覆盖了绝大多数中英文排版场景；如果你还想补充中文等宽字体或服内特色字体：

1. 将 `.ttf` 或 `.otf` 字体文件放入 `plugins/HikariCanvas/fonts/` 目录（不存在则手动新建；暂不支持 `.ttc` / `.otc` 字体合集包）。
2. **检查文件名格式**：去掉扩展名后的文件名会直接作为字体 ID，**只能包含英文字母、数字、下划线 `_` 或连字符 `-`**，不能包含中文、空格或多余的小数点。
   - 正确示例：`SourceHanMono-Regular.otf`、`fusion_pixel_12px.ttf`
   - 错误示例（会被跳过并在后台打警告）：`思源等宽.otf`、`My Font.ttf`、`font.v2.ttf`
3. **重启服务器**。插件启动时会自动在后台计算新字体的字符宽度表，几秒内即可在网页编辑器的字体下拉框里选到。

### 5.2 添加自定义矢量图标（`plugins/HikariCanvas/icons/`）

如果你想往编辑器的图标库里塞入服务器徽标或地铁线路小图标：

1. 准备包含单个 `<path d="...">` 的简洁 `.svg` 文件，文件名同样只用**英文字母、数字、`_` 或 `-`**（如 `line1_badge.svg`）。
2. 放入 `plugins/HikariCanvas/icons/` 目录并**重启服务器**，编辑器左侧「图标库」里就会多出一组 `user/` 自定义图标。
   - 如果是多路径、多颜色的复杂 SVG 插画，不需要放进这个目录，直接让创作者在网页编辑器顶栏「更多 → 导入 SVG」里按图形导入即可。

### 5.3 投放全服公共模板（`plugins/HikariCanvas/templates/`）

服主做好一套标准站牌或商铺模板后，可以先在编辑器里点「存为模板」生成模板包，或者把做好的 `.canvas` 模板包文件直接放进 `plugins/HikariCanvas/templates/` 目录，然后在游戏或控制台执行：

```text
/canvas reload templates
```

无需重启服务器，全服所有玩家打开模板库都能立刻看到并免费套用这套公共模板（不受 `canvas.template.use-others` 权限限制）。
