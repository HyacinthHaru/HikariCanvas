# 0.7.2-P3 重复直到条件 + 全服广播 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development。Steps 用 checkbox。

**Goal:** 加「重复直到条件」流程积木 + 「全服广播」（sendMessage 加 target）。

**Architecture:** 后端为主。**RepeatUntil**（F6）= ScriptRunner 动态循环（不预展开，每轮查 condition + 压回自身 + 压 body），轮数用 RunState 的 `Map<blockId,int>` 记，Budget 50 + maxIterations 100 双闸。**全服广播**（F7）= 既有 `SendMessage` record 加 `target` 字段（trigger 默认 / all），executor doSendMessage 按 target 分流，向后兼容旧 payload。

**Tech Stack:** Java 21（JUnit5）+ Vue3/TS（vitest）。协议 v5 不变。

**契约:** `docs/scripting-0.7.2.md` §4.2/§4.3 + F6/F7 + §8（已固化：while 语义 / maxIterations∈[1,100] 默 10 / RunState Map 记轮数 / sendMessage 加 target 下拉）。

**测试基线:** 后端 1781 / 前端 1135。

**wire 字段名:** repeatUntil `{condition, maxIterations, body}` / sendMessage 加 `target`（"trigger"|"all"，默 trigger）。

- [ ] **Step 3b: runFrames 加 RepeatUntil 分支**（Repeat 分支附近）

```java
if (a instanceof Action.RepeatUntil ru) {
    int rounds = st.repeatUntilRounds.getOrDefault(blockId, 0);
    boolean cond;
    try {
        cond = conditions.eval(ru.condition(), st.wallId);
    } catch (RuntimeException e) {
        cond = false; // 坏条件按未满足，靠 maxIterations 兜底
    }
    if (cond || rounds >= ru.maxIterations()) {
        st.repeatUntilRounds.remove(blockId); // 清轮数（下次 run / 同 run 后续不串）
        st.trace.add(TraceStep.ok(blockId, "action",
                cond ? "repeatUntil 条件满足" : "repeatUntil 达上限"));
        i++; // 跳出循环，内层 while 继续后续 acts[i+1]
        continue;
    }
    st.repeatUntilRounds.put(blockId, rounds + 1);
    st.trace.add(TraceStep.ok(blockId, "action", "repeatUntil 第 " + (rounds + 1) + " 轮"));
    // 压回自身（Frame(acts, i)：从 RepeatUntil 开始，含其后续）+ 压一轮 body（LIFO body 先执行）。
    // body 执行完弹回 Frame(acts,i) → 重新进入 RepeatUntil 再查 condition。
    stack.push(new Frame(acts, i, f.prefix()));
    stack.push(new Frame(ru.body(), 0, blockId + "/body/")); // blockId 同构不带轮数（照 Repeat）
    continue outer;
}
```

> 关键：① while 语义（先查 condition，满足→0 次 body）；② 压回 `Frame(acts, i)`（i 不变，含后续——跳出时 i++ 在同帧执行后续）；③ blockId `<blockId>/body/<j>` 不带轮数（守 0.7.0 同构）；④ RepeatUntil 自身每轮进入计 1 actionCount（循环顶 ++）+ body 计入 → Budget 50 先于 maxIterations 100 兜底（防 condition 永 false 失控）。

## P3 完整实测闸

1. **重复直到**：规则「重复直到 `var("user/x") > 3`（最多 10）→ 体内 变量增加 user/x +1 + 发消息」→ 触发 → 看 x 涨到 4 停、消息发 4 次；condition 一开始就满足 → body 0 次
2. **死循环防护**：条件永不满足 → 不卡服（Budget 50 熔断 + maxIterations 100）
3. **全服广播**：「发消息 发给=全服 "大家好"」→ 触发 → 全服所有人收到；发给=触发玩家 → 只触发者收到
4. **向后兼容**：P5 之前存的 sendMessage 脚本（无 target）加载 → 默认发给触发玩家，不报错
