# 0.7.1-P3 预览框左右分栏 + 元素点选取当前值 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 把积木脚本编辑器从全屏单画布改成左右分栏（左积木 + 右预览框），预览框复用现有墙渲染显示当前墙现状，并支持「在预览里点选元素 = 绑定该元素 + 取其当前坐标填进积木」。

**Architecture:** 纯前端（不碰协议/后端，E3 决策）。预览框 `PreviewPane` 用 canvas 2D 复用 `renderProjectState` 渲当前墙（只读），叠一层点选 hit-test（复用 Live Paint 的 `elementToPolygon`/`pointInPolygon`）。坐标系 `previewToWall`/`wallToPreview`（fit-scale + 居中偏移）—— P3 建立，P4 幽灵拖动用。点预览元素 → 填到 `scriptEdit.activeElementBinding`（新增）记录的当前积木 elementId 字段 + 取当前坐标值（深度2）。

**Tech Stack:** Vue 3 + Canvas 2D（复用 PreviewRenderer）+ Pinia（ui/scriptEdit store）+ vitest/@vue/test-utils。

**契约：** `docs/scripting-0.7.1.md` §2（核心交互）+ §8（P3 范围）。**P3 = 深度2（点选取当前值）；P4 = 深度3（幽灵拖动设目标），不在本计划。**

## 决策（贯穿全计划）

| 项 | 决定 |
|---|---|
| 协议/后端 | **零改**（E3 纯前端） |
| 预览渲染性能（§9） | **先全量重绘**（watch project.state deep → renderProjectState）。元素多时脏区优化**留实测**（工具不是保姆，简单优先；P3 实测闸看卡不卡再定） |
| 坐标系 | `previewToWall(px,py)` / `wallToPreview(x,y)`：fit-scale（`scale = min(paneW/wallW, paneH/wallH)`）+ 居中偏移。墙像素 = `widthMaps*128 × heightMaps*128` |
| 点选 hit-test | 复用 `web/src/livepaint` 的 `elementToPolygon` + `pointInPolygon`（倒序 z-order，精确含旋转） |
| 点选取当前值（深度2） | 点预览元素 → ① 填当前活跃积木的 `elementId` ② 对坐标/尺寸/旋转/透明度类 friendly 积木，取元素当前 `x/y/w/h/rotation/opacity` 填进对应 patch；非坐标类（改文字/改颜色）只填 elementId |
| 当前活跃字段 | 新增 `scriptEdit.activeElementBinding`（当前聚焦的 elementId 字段所属积木 path）。element 字段 focus/click 时 set；切积木/blur 清 |
| 元素高亮 | 当前积木绑定的 elementId 元素在预览**描边高亮**（E4） |
| 布局 | ScriptEditorOverlay `canvas-host` → 左 BlockCanvas + 中分隔条 + 右 PreviewPane；可拖宽 + 折叠；状态存 ui store + localStorage（照 SNAP_KEY 范例） |

const SCRIPT_PREVIEW_KEY = 'hikari-canvas:script-preview';
const scriptPreviewCollapsed = ref(loadScriptPreviewCollapsed());
const scriptPreviewWidthPct = ref(loadScriptPreviewWidthPct()); // 右预览框占整体宽度 %

function loadScriptPreviewCollapsed(): boolean {
    try {
        const raw = localStorage.getItem(SCRIPT_PREVIEW_KEY);
        if (!raw) return false;
        const p = JSON.parse(raw) as { collapsed?: unknown };
        return typeof p.collapsed === 'boolean' ? p.collapsed : false;
    } catch { return false; }

function loadScriptPreviewWidthPct(): number {
    try {
        const raw = localStorage.getItem(SCRIPT_PREVIEW_KEY);
        if (!raw) return 35;
        const p = JSON.parse(raw) as { widthPct?: unknown };
        return typeof p.widthPct === 'number' ? Math.max(20, Math.min(70, p.widthPct)) : 35;
    } catch { return 35; }
}
watch([scriptPreviewCollapsed, scriptPreviewWidthPct], () => {
    try {
        localStorage.setItem(SCRIPT_PREVIEW_KEY, JSON.stringify({
            collapsed: scriptPreviewCollapsed.value,
            widthPct: scriptPreviewWidthPct.value,
        }));
    } catch { /* ignore */ }

function setScriptPreviewWidthPct(pct: number): void {
    scriptPreviewWidthPct.value = Math.max(20, Math.min(70, pct));
}
function toggleScriptPreview(): void {
    scriptPreviewCollapsed.value = !scriptPreviewCollapsed.value;
}

- [ ] **Step 1: 写失败测试（坐标系纯函数）** —— `computePreviewTransform(wallW, wallH, paneW, paneH)` 返回 `{scale, offsetX, offsetY}`（fit + 居中）；`wallToPreview`/`previewToWall` 互逆（round-trip 误差 < 0.5px）；墙比预览大/小都对。

```typescript
// previewCoords.ts 期望 API
export interface PreviewTransform { scale: number; offsetX: number; offsetY: number; }
export function computePreviewTransform(wallW: number, wallH: number, paneW: number, paneH: number): PreviewTransform;
export function wallToPreview(t: PreviewTransform, x: number, y: number): { x: number; y: number };
export function previewToWall(t: PreviewTransform, px: number, py: number): { x: number; y: number };
```
```typescript
// 实现
export function computePreviewTransform(wallW, wallH, paneW, paneH) {
    if (wallW <= 0 || wallH <= 0 || paneW <= 0 || paneH <= 0) return { scale: 1, offsetX: 0, offsetY: 0 };
    const scale = Math.min(paneW / wallW, paneH / wallH);
    const offsetX = (paneW - wallW * scale) / 2;
    const offsetY = (paneH - wallH * scale) / 2;
    return { scale, offsetX, offsetY };
}
export function wallToPreview(t, x, y) { return { x: t.offsetX + x * t.scale, y: t.offsetY + y * t.scale }; }
export function previewToWall(t, px, py) { return { x: (px - t.offsetX) / t.scale, y: (py - t.offsetY) / t.scale }; }
```
