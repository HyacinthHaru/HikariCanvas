```java
package moe.hikari.canvas.script;

import com.fasterxml.jackson.databind.annotation.JsonDeserialize;
import com.fasterxml.jackson.databind.annotation.JsonSerialize;

/**
 * 0.7.0 脚本触发器(帽子积木)多态联合。契约 docs/scripting.md §2.2。
 * wire 形态:扁平字段 + type 判别(camelCase),照 KfValue 双向自定义序列化范式。
 */
@JsonSerialize(using = TriggerSerializer.class)
@JsonDeserialize(using = TriggerDeserializer.class)
public sealed interface Trigger permits
        Trigger.VariableChange, Trigger.Timer, Trigger.PlayerJoin,
        Trigger.PlayerKill, Trigger.PlayerNear, Trigger.WallReady {

    /** wire type 判别串。 */
    String wireType();

    record VariableChange(String fullName) implements Trigger {
        @Override public String wireType() { return "variableChange"; }
    }
    record Timer(int intervalSeconds) implements Trigger {
        @Override public String wireType() { return "timer"; }
    }
    record PlayerJoin() implements Trigger {
        @Override public String wireType() { return "playerJoin"; }
    }
    record PlayerKill() implements Trigger {
        @Override public String wireType() { return "playerKill"; }
    }
    record PlayerNear(int rangeBlocks) implements Trigger {
        @Override public String wireType() { return "playerNear"; }
    }
    record WallReady() implements Trigger {
        @Override public String wireType() { return "wallReady"; }
    }
}
```

Serializer(`TriggerSerializer extends JsonSerializer<Trigger>`):`gen.writeStartObject(); gen.writeStringField("type", value.wireType());` 然后 switch pattern-match 各子类写自有字段;`writeEndObject()`。
Deserializer(`TriggerDeserializer extends JsonDeserializer<Trigger>`):`JsonNode node = p.readValueAsTree();` 取 `node.get("type")`(缺失/非文本 → `ctxt.reportInputMismatch`),switch type 串构造对应 record(int 字段 `node.path("fieldName").asInt(默认值不允许——缺失同样 reportInputMismatch)`),default 分支 reportInputMismatch("unknown trigger type")。

```java
@JsonSerialize(using = ActionSerializer.class)
@JsonDeserialize(using = ActionDeserializer.class)
public sealed interface Action permits
        Action.SetVariable, Action.IncrementVariable, Action.SetElementProperty,
        Action.PlayTimeline, Action.PlaySound, Action.Wait,
        Action.RunCommand, Action.Log, Action.If {

    String wireType();

    record SetVariable(String fullName, String value) implements Action {
        @Override public String wireType() { return "setVariable"; } }
    record IncrementVariable(String fullName, double delta) implements Action {
        @Override public String wireType() { return "incrementVariable"; } }
    record SetElementProperty(String elementId, String property, String value) implements Action {
        @Override public String wireType() { return "setElementProperty"; } }
    /** op = play|pause|seek;seekMs 仅 seek 时非 null。 */
    record PlayTimeline(String timelineId, String op, Long seekMs) implements Action {
        @Override public String wireType() { return "playTimeline"; } }
    /** scope = near|all。 */
    record PlaySound(String soundId, double volume, double pitch, String scope) implements Action {
        @Override public String wireType() { return "playSound"; } }
    record Wait(long ms) implements Action {
        @Override public String wireType() { return "wait"; } }
    record RunCommand(String templateId, java.util.Map<String, String> params) implements Action {
        @Override public String wireType() { return "runCommand"; } }
    record Log(String message) implements Action {
        @Override public String wireType() { return "log"; } }
    /** elseActions 命名避开 java 关键字;wire 字段名仍是 "else"。空分支 = 空 list(非 null)。 */
    record If(String condition, java.util.List<Action> then,
              java.util.List<Action> elseActions) implements Action {
        @Override public String wireType() { return "if"; } }
}
```

Deserializer 的 if 分支递归:`then`/`else` 数组逐元素 `ctxt.readTreeAsValue(elem, Action.class)`(Jackson 2.13+ API,项目 2.18.2 可用);缺失分支按空 list。Serializer 的 If 分支写 `"then"` / `"else"` 字段名(elseActions → "else")。RunCommand.params 反序列化后用 `Map.copyOf` 防外部可变引用;If.then/elseActions 用 `List.copyOf`(record 紧凑构造器里做)。
