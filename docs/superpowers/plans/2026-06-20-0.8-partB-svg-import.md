# 0.8 Part B：SVG 矢量导入 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让玩家把一个静态 SVG 文件导入成一组**可编辑、可缩放、可绑变量的原生 `PathElement`**（+ 内嵌位图 → `ImageElement`），插入当前工程。

**Architecture:** SVG 在**前端**用 `DOMParser` 解析 → 每个 `<path>`/基本形状 → 一个 `PathElement`（不新增元素类型）；`d` 归一化到 `PathElement` 可渲染子集 `M/L/Q/C/Z`（A/S/T/H/V 展开）；transform 烘焙进坐标；fill/stroke/fill-rule 映射到现有 `Fill`/`Stroke` + 新增 `fillRule` 字段；动画取首帧静态化；一组元素循环发 `element.add`（server-authoritative，前端不直接 mutate store）。后端 `PathParser` 已支持全文法，零新解析器；唯一动数据模型的是 `fillRule`。

**Tech Stack:** 前端 Vue 3 + TS + Vitest + happy-dom（DOMParser 测试）+ 浏览器原生 `DOMParser`；后端 Java 21 + `java.awt`（`PathRenderer` winding rule）。

## Global Constraints

- **不新增元素类型**：SVG 产物复用 `PathElement` / `ImageElement`（D5）。
- **动画 SVG 取首帧静态化**：丢弃 `<animate>`/CSS 动画，取 t=0 静态值（D5）。
- **前端解析 + d 归一化到 `M/L/Q/C/Z` 子集**；后端零新 path 解析器（D6）。
- **fill-rule 按 SVG 承载**：新增 `PathElement.fillRule?: 'nonzero' | 'evenodd'`，`null`/缺省 = `nonzero`（旧行为，无需迁移）（D9）。
- **不做**：`<text>` / `clipPath` / `mask` / `<filter>` / SMIL+CSS 动画 / `<foreignObject>` / 外部 `href` 引用（含 `<image href=http…>`）/ `<use>`·`<symbol>`（D10）。
- **server-authoritative**：前端创建元素一律 `getWsClient().send('element.add', {type, props, layerId})`，**不直接 mutate store**；刷新靠后端 `state.patch`/`state.snapshot` 推回。一组 SVG = 循环 N 条 `element.add`（接受 N 次撤销，与 clipboard 粘贴一致；本期不加后端 group op）。
- **双端渲染一致**：前端 `PreviewRenderer.ts` 与后端 `PathRenderer.java` 对 `fillRule` 的处理必须逐函数对齐（项目硬纪律）。
- **测试环境**：用到 `DOMParser` 的测试文件首行加 `// @vitest-environment happy-dom`（已装）；纯几何/d-归一化逻辑留 node 环境。
- **大白话文案**：UI / 提示禁开发黑话。

| # | 决策 | 结论 | 依据 |
|---|---|---|---|

```ts
export class SvgImportError extends Error {
    constructor(public code: string, message: string) { super(message); }
}

/** 解析前闸：体积上限 + 拒 XML 实体（DOCTYPE/ENTITY，防十亿笑 + XXE 表面）。 */
export function preParseGuard(svg: string, maxBytes: number): void {
    if (svg.length > maxBytes) {
        throw new SvgImportError('SVG_TOO_LARGE', `SVG 体积 ${svg.length} 超过上限 ${maxBytes}`);
    }
    if (/<!DOCTYPE/i.test(svg) || /<!ENTITY/i.test(svg)) {
        throw new SvgImportError('SVG_HAS_ENTITY', 'SVG 含 DOCTYPE/ENTITY，已拒绝');
    }
}

const DANGEROUS_TAGS = ['script', 'foreignObject', 'use', 'symbol', 'animate', 'animateTransform', 'animateMotion', 'set', 'style'];

/** 解析后闸：原地剥离危险节点 + on* 事件属性 + 外链 image。D10 不支持项一并剔除。 */
export function stripDangerous(root: Element): void {
    // 危险标签（含动画——D5 取首帧静态化 = 丢动画节点）
    for (const tag of DANGEROUS_TAGS) {
        root.querySelectorAll(tag).forEach((n) => n.remove());
    }
    // on* 事件 + 外链 href（http/https/javascript）+ 外部 image
    const walk = (el: Element) => {
        for (const attr of [...el.attributes]) {
            if (/^on/i.test(attr.name)) el.removeAttribute(attr.name);
            if ((attr.name === 'href' || attr.name === 'xlink:href')
                && /^(https?:|javascript:)/i.test(attr.value)) {
                el.remove(); return;
            }
        }
        [...el.children].forEach(walk);
    };
    walk(root);
}
```

```ts
import { preParseGuard, stripDangerous, SvgImportError } from './svgSecurity';

export interface SvgDoc {
    root: SVGSVGElement;
    shapes: Element[];
    viewBox: [number, number, number, number] | null;
    width: number | null;
    height: number | null;
}

const SHAPE_TAGS = new Set(['path', 'rect', 'circle', 'ellipse', 'line', 'polyline', 'polygon', 'image']);

export function parseSvg(svg: string, maxBytes = 512 * 1024): SvgDoc {
    preParseGuard(svg, maxBytes);
    const doc = new DOMParser().parseFromString(svg, 'image/svg+xml');
    if (doc.querySelector('parsererror')) throw new SvgImportError('SVG_MALFORMED', 'SVG 解析失败');
    const root = doc.documentElement as unknown as SVGSVGElement;
    stripDangerous(root);
    const shapes: Element[] = [];
    const walk = (el: Element) => {
        if (SHAPE_TAGS.has(el.tagName.toLowerCase())) shapes.push(el);
        [...el.children].forEach(walk);
    };
    walk(root);
    return { root, shapes, viewBox: parseViewBox(root.getAttribute('viewBox')),
        width: parseLen(root.getAttribute('width')), height: parseLen(root.getAttribute('height')) };
}

function parseViewBox(v: string | null): [number, number, number, number] | null {
    if (!v) return null;
    const n = v.trim().split(/[\s,]+/).map(Number);
    return n.length === 4 && n.every(Number.isFinite) ? [n[0], n[1], n[2], n[3]] : null;
}
function parseLen(v: string | null): number | null {
    if (!v) return null;
    const n = parseFloat(v);   // 忽略单位（px 默认）；% 等留 null
    return Number.isFinite(n) ? n : null;
}
```
