# 0.8.3 i18n 收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收掉 0.8.2 留下的两处 i18n 缺口——benchmark 压测的玩家可见摘要与磁盘报告做真 i18n，脚本试跑诊断（script.trace detail）统一英文化——让插件本体不再有"中英混杂"或"硬编码中文发给玩家"的残留。

**Architecture:** 沿用 0.8.2 既有 i18n 设施（`i18n/Messages` + `lang/{en_us,zh_cn}.yml`，MiniMessage 渲染 + 命名占位符 + `Player.getLocale()` 选语言）。两条独立路线：
- **A. benchmark**：两个 driver（`ScriptBenchmarkDriver`/`TweenBenchmarkDriver`）从"返回成品中文字符串"改为"返回结构化数据行"，由 `BenchmarkSubCommand` 拿 `Messages` + **玩家 locale** 组装标题/列头/数据行/脚注（真 per-player i18n）；磁盘文件 `summary.txt`（`renderReportText`）改为按 **config `default-locale`** 渲染（文件不分人）。
- **B. script.trace**：`ActionExecutor`/`ScriptRunner`/`ElementPropertyApplier` 三个执行引擎里约 100 处 `TraceStep.detail` 与诊断日志的中文**就地英文化**，不进 lang、不改 `TraceStep` 结构、不碰前端（detail 当前前端未显示；真 per-player i18n 等将来做 detail 展示 UI 时连 `TraceStep` 重构一起做）。

**Tech Stack:** Java 21 / Paper API 1.21.11 / Gradle；Adventure `Component` + MiniMessage；`Placeholder.unparsed`；JUnit 5。纯后端，无前端改动。

## Global Constraints

- **不动 Javadoc / 代码注释**：全项目注释皆中文，保持一致；本计划只改"运行时字符串字面量"（`TraceStep.detail`、异常 message、`LOG` 文本、发给玩家的文案）。
- **lang 文件 zh/en 必须对齐**：每加一个 key 必须 zh_cn + en_us 各一份；`LangFileParityTest` 必须保持绿。
- **en_us 值必须是英文**，zh_cn 值必须是中文（parity 测试不查"en 里混中文"，靠实现 + review 把关）。
- **chat 文案的 lang 值带 MiniMessage 颜色标签**（如 `<gray>`/`<gold>`），沿用 0.8.2 既有 bench 段风格；**summary.txt 的 `report-file.*` 文件文案为纯文本**（无颜色标签——写进 .txt 文件，不要标签泄漏）。
- **git 纪律**：每 task 独立 commit，SSH 签名，**禁止 `git add -A`**（工作区有未跟踪 scratch `findings.md`/`progress.md`/`task_plan.md` 不得扫入；只 `git add` 本 task 明确涉及的文件）；提交 push 留到全部完成后由 controller 统一处理（本计划各 task 只 commit 不 push）。
- **不 bump 版本号 / 不写 journal**，直到最后的收尾 task。
- **测试纪律（0.8.2 的教训）**：迁移/英文化改了字符串后，**必须实际跑受影响的测试套件**（不能只编译 + grep）——0.8.2 两次回归都因 per-task 验证只编译没跑套件。每个 task 的"验证"步骤明确点名要跑的测试类。

```java
/** 把 driver 返回的结构化行按玩家 locale 组装成 done/subtitle/表头/数据行/脚注发出。 */
private void sendBenchRows(CommandSender sender, String which, int measured, int warm,
                           List<moe.hikari.canvas.benchmark.BenchRow> rows) {
    String base = "command.bench." + which;
    messages.send(sender, base + ".done");
    messages.send(sender, base + ".subtitle",
            Placeholder.unparsed("measured", String.valueOf(measured)),
            Placeholder.unparsed("warmup", String.valueOf(warm)));
    messages.send(sender, base + ".table-header");
    for (moe.hikari.canvas.benchmark.BenchRow r : rows) {
        var p = r.p();
        messages.send(sender, base + ".row",
                Placeholder.unparsed("n", String.format("%-8d", r.n())),
                Placeholder.unparsed("p50", String.format("%8.4f", p.p50())),
                Placeholder.unparsed("p95", String.format("%8.4f", p.p95())),
                Placeholder.unparsed("p99", String.format("%8.4f", p.p99())),
                Placeholder.unparsed("mean", String.format("%8.4f", p.mean())),
                Placeholder.unparsed("max", String.format("%8.4f", p.max())));
    }
    messages.send(sender, base + ".note");
}
```
删掉旧 body 里 `String summary = ...split("\n")...sender.sendMessage(Component.text(line, GRAY))` 的逐行发送 + 现在多余的 `Component`/`NamedTextColor` 内联引用（若该文件别处不再用到这两个全限定名，可不引入 import；helper 未用到它们）。`messages.send(sender, base + ".done")` 取代原先单独的 `run-tween.done` send。
