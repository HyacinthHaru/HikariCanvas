# 0.7.1-P2 新触发器 + 有界循环 + 协议 v5 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 加 3 个新触发器（右键墙 / 玩家离开靠近区域 / 玩家退服）+ 有界循环「重复 N 次」+ 协议 v4→v5 干净升版。

**Architecture:** Trigger 加 3 个 record（照现有 6 触发器 wire 范式），TriggerRouter 加路由（quit 全局索引 / rightClickWall 按墙索引 / playerLeaveRange 复用 PlayerNearSampler 加「离开沿」），GameEventListenerHub 加 2 个 Bukkit handler（PlayerQuitEvent / PlayerInteractEntityEvent + FrameDeployer 反查 wallId）。Repeat 是新 Action，由 ScriptRunner 展开 count 轮 body（**blockId 不带 round 前缀，守 0.7.0 同构**）。协议 v5 = 后端 SUPPORTED_MIN/MAX=5 + 前端 CLIENT_V=5 干净切换。

**Tech Stack:** Java 21（sealed Trigger/Action + 手写 Jackson wire）/ Vue 3 + TS / JUnit 5 纯 fake / vitest。

**契约：** `docs/scripting-0.7.1.md`（§5 循环 / §6 触发器 / §7 协议 / §9 预警决策回填）+ `docs/scripting.md`（基座）。

## 命名 + 决策（贯穿全计划，不可偏离）

| 项 | 决定 |
|---|---|
| 右键墙触发器 wireType | `rightClickWall`（**非** wallInteract） |
| 玩家离开区域 wireType | `playerLeaveRange` |
| 玩家退服 wireType | `playerQuit` |
| 循环 Action wireType | `repeat` |
| **Repeat blockId** | 展开 count 轮 body 用**同一 prefix** `blockId/body/<i>`，**不带 round** —— 前端 body 只一份，带 round 会破坏前后端同构。trace 同 blockId 重复 = 执行多次高亮多次（正确语义） |
| playerLeaveRange 实现 | 复用 PlayerNearSampler，NearEntry 加 `leaveEdge` 标记，sample 检测「离开沿」（in: true→false） |
| 权限面（§6） | `rightClickWall` + `playerQuit` → `NODE_TRIGGER_GLOBAL`（全局事件）；`playerLeaveRange` → 基础 `NODE_EDIT`（墙级，同 playerNear） |
| §9 展开预警 | **不做前端预估警告** —— 靠运行时 Budget 熔断（超 50 动作 → blocked + 试跑 trace 可见）。`countBlocks` 仍计 repeat 的 body 节点（不乘 count，是积木树节点数硬限 50，非展开数） |
| 协议 v5 | `Protocol.SUPPORTED_MIN/MAX = 5`；前端 `CLIENT_V = 5`。干净切换，握手范围检查自动覆盖 |

**编译依赖（穷尽 switch 守门）：** Trigger 加 record → `TriggerSerializer` + `TriggerDeserializer` 2 处穷尽 switch 编译失败直到补 case；Action 加 Repeat → `ActionExecutor`/`ActionSerializer`/`ActionDeserializer`/`ScriptRuleValidator`/`ScriptPermissions.scanActions` 5 处。**一次加全 record + 全部 case 再编译。** ScriptPermissions 的 trigger 判定是 if-instanceof（不穷尽，手动加）。
