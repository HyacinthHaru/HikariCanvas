# 0.7.2-P2 元素积木 + 变量积木 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development。Steps 用 checkbox。

**Goal:** 加 4 个脚本动作：克隆元素 / 删除元素 / 变量复制 / 文本拼接。

**Architecture:** 后端为主，照 0.7.1-P5 全栈范式（record + 序列化 + validator + executor + permissions + 前端镜像）。**变量积木**（复制/拼接）直接复用 `doSetVariable` 的 `store.get`+`store.setValue`+`interpolator.interpolate`，async 无主线程 hop。**元素积木**（克隆/删除）走 `ElementPropertyApplier` 双路径（session seam + headless）——删除复用已有 `EditSession.deleteElement`，克隆新增 `EditSession.cloneElement`（复用已有 `cloneElementWithNewId` + 偏移），照 `applyNudge` 范式加 `applyClone`/`applyDelete`。

**Tech Stack:** Java 21（JUnit5 + MockBukkit）+ Vue3/TS（vitest）。协议 v5 不变（新 type 是 v5 内扩展）。

**契约:** `docs/scripting-0.7.2.md` §4 + F5/F8/F10。

**测试基线:** 后端 1731 / 前端 1131。

**wire 字段名（双端必须一致）:** copyVariable `{target, source}` / appendVariable `{fullName, text}` / cloneElement `{elementId, offsetX, offsetY}` / deleteElement `{elementId}`。

```java
private TraceStep doCopyVariable(String wallId, String blockId, Action.CopyVariable a) {
    if (store == null) return TraceStep.error(blockId, "VariableStore 未装配");
    String src = VariableInterpolator.resolveFullName(a.source(), wallId);
    String dst = VariableInterpolator.resolveFullName(a.target(), wallId);
    var srcVar = store.get(src).orElse(null);
    if (srcVar == null) return TraceStep.error(blockId, "源变量不存在: " + src);
    String value = srcVar.currentValue() != null ? srcVar.currentValue()
            : (srcVar.defaultValue() != null ? srcVar.defaultValue() : "");
    try {
        store.setValue(dst, value, null);
    } catch (VariableException e) {
        return TraceStep.error(blockId, "copyVariable " + dst + ": " + e.getMessage());
    }
    return TraceStep.ok(blockId, "action", dst + " ← " + src);
}

private TraceStep doAppendVariable(String wallId, String blockId, Action.AppendVariable a) {
    if (store == null || interpolator == null) return TraceStep.error(blockId, "VariableStore 未装配");
    String dst = VariableInterpolator.resolveFullName(a.fullName(), wallId);
    String add = interpolator.interpolate(a.text(), wallId).text();
    var cur = store.get(dst).map(v -> v.currentValue() != null ? v.currentValue() : "").orElse("");
    try {
        store.setValue(dst, cur + add, null);
    } catch (VariableException e) {
        return TraceStep.error(blockId, "appendVariable " + dst + ": " + e.getMessage());
    }
    return TraceStep.ok(blockId, "action", dst + " += ...");
}
```

```java
public synchronized OpResult cloneElement(String elementId, int offsetX, int offsetY) {
    if (elementId == null) return err("INVALID_PAYLOAD", "elementId missing");
    Locator loc = findElement(elementId);
    if (loc == null) return err("INVALID_ELEMENT", "element not found: " + elementId);
    if (loc.layer.locked()) return err("LAYER_LOCKED", "owning layer is locked");
    // F10 配额：每墙元素总数上限。
    if (maxElementsPerWall != null && maxElementsPerWall > 0 && totalElements() >= maxElementsPerWall) {
        return err("QUOTA_EXCEEDED", "元素总数已达上限 " + maxElementsPerWall);
    }
    Element cloned = withOffset(cloneElementWithNewId(loc.element), offsetX, offsetY);
    ProjectSnapshot pre = snapshotNow();
    loc.layer.elements().add(cloned); // 加到原元素所在 layer 末尾
    commitHistory(pre);
    long v = state.bumpVersion();
    int newIdx = loc.layer.elements().size() - 1;
    return new OpResult.Ok(
            new StatePatchBuilder().add(elementPath(loc.layerIdx, newIdx), cloned).build(v),
            DirtyRegion.of(cloned));
}
```

```java
public TraceStep applyClone(String wallId, String blockId, String elementId, int offsetX, int offsetY) {
    if (sessionApplier != null) {
```

2. **克隆元素**：规则「克隆元素 X 偏移 (10,10)」→ 触发 → 画板多一个 X 的副本（偏移位置）；连点几次配额上限后停（不崩）
3. **变量复制**：`user/a=5` → 规则「变量复制 a→b」→ 触发 → `user/b` 变 5
4. **文本拼接**：`user/log="["` → 规则「文本拼接 log += "x=${var:user/x}"」→ 触发 → log 末尾追加
5. **双路径**：编辑器开着时触发（session 路径）+ 关掉浏览器后游戏内触发（headless 路径），元素增删都生效
