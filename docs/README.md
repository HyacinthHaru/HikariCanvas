# HikariCanvas 文档导览

仓库里的文档分成两类：**上半区是面向玩家、服主与外部插件作者的使用与运维手册**，**下半区是面向核心开发与维护者的架构与实现契约**。你可以按自己的需求直接跳到对应入口：

### 按身份快速查找

- **我是玩家 / 创作者**：先看 [玩家与服主使用手册](user-guide.md) 了解建墙命令与网页编辑器工具；需要接入动态数字或做站台屏看 [变量与铁路教程](variables.md)，做关键帧动画看 [时间轴动画指南](timeline-guide.md)，做右键点击或玩家靠近等互动逻辑看 [积木脚本指南](scripting-guide.md)。
- **我是服主 / 运维**：装服与配置公网 HTTPS 反向代理看 [部署指南](deployment.md)；配 LuckPerms 权限与加自定义字体、图标、公共模板看 [玩家与服主使用手册（第四、五部分）](user-guide.md#第四部分服主权限配置指南)；测算服务器能挂多少块动态画布看 [性能压测指南](benchmark.md)；遇到异常查 [常见问题排错](troubleshooting.md)。
- **我想从自己的插件往招牌推数据**：直接阅读 [外部插件接入 API](api.md)，并可参考仓库 [`examples/`](../examples/README.md) 下两份可直接编译运行的示例插件。
- **我想参与二次开发（或让 AI 协助维护源码）**：先读 [构建与二次开发指南](development.md) 跑通编译测试并熟悉工程边界，改动具体模块前再对照下方的技术契约文档。
