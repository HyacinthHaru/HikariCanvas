# HikariCanvas 时间轴动画使用指南

让招牌动起来——文字淡入、图标移动、数字滚动，还能让它"数据变了就播"。

> 这是**给玩家 / 服主看的大白话教程**。想看内部设计（数据结构 / 协议 / 双端一致性数学）去
> `docs/timeline.md`（设计总纲）。

---

## 第一部分：做你的第一个动画

### 1.1 时间轴动画是什么

普通招牌是**静止**的。时间轴让招牌上的元素**随时间变化**：位置、大小、旋转、透明度、颜色、文字
都能动。你只要标几个"关键时刻"（关键帧），中间的过渡系统自动补。

一句话：**你定起点和终点，它自动让元素从起点平滑动到终点。**

### 1.2 打开时间轴

编辑器顶部点 **胶片图标**（🎬）打开底部的时间轴面板（dock）。第一次用点「新建时间轴」。

面板分两半：左边是元素列表，右边是时间轴（有刻度、播放头、关键帧）。

### 1.3 给元素加关键帧——"拉就设"

最简单的方式，跟 PR / AE 一样：

1. 在画布上点选一个元素 → 时间轴左边出现这个元素的行。
2. 确认 dock 顶部那个**红点按钮**（自动加帧）是亮的。
3. 播放头停在 **0 秒** → 把元素拖到**起点**位置 → 自动记下一帧。
4. 把播放头拖到比如 **2 秒** → 把元素拖到**终点**位置 → 又自动记一帧。
5. 完成。元素会在 0→2 秒之间从起点动到终点。

> 不想自动记？把红点按钮点灭，拖元素就只是普通挪位置。也可以点元素行的 **+** 按钮在播放头手动打一帧。

### 1.4 缓动——让动作有快慢

默认是**匀速**。想让它"先慢后快""两头慢中间快"（更自然）：

1. 点选一个**整体关键帧块**（元素行上的紫色菱形）。
2. dock 顶部出现**曲线按钮** → 点开缓动编辑器。
3. 选预设（匀速 / 由慢到快 / 由快到慢 / 两头慢中间快），或拖控制点自定义。

> 缓动是**统一管整组**的，所以横竖移动同步，运动轨迹保持直线——只是速度有快慢，不会把直线掰弯。

### 1.5 整体帧 vs 单属性

- **整体关键帧**（元素行上的紫菱形）：一个块记录元素**这一刻的全部几何**（位置/大小/旋转/透明度）。
  日常用这个就够了——选、删、拖时刻、调缓动都对着它。
- **单属性微调**：点元素左边的三角**展开**，能看到每个属性（横坐标/纵坐标/…）各自的子轨，点单个
  小帧能单独选 / 删，做精细控制。

### 1.6 关键帧的直接操作

- **选**：点一下整体帧块（Shift + 点 = 多选）。
- **批量删**：在时间轴空白处**拉个框**框住若干帧 → 按 Del / Backspace 一次全删。
- **改时刻**：按住整体帧块**左右拖**。
- **逐属性删**：展开后点单个小帧 → Del。

### 1.7 播放方式

dock 设置里「播放方式」三选一：

| 选项 | 效果 |
|---|---|
| 播放一次 | 从头播到尾就停 |
| 循环播放 | 播完从头再来，一直转 |
| 来回播 | 正着播一遍、倒着播一遍，往复 |

### 1.8 在编辑器里预览

dock 顶部有播放 / 回到开头按钮，拖播放头能**手动检视**每一帧。这是**编辑器本地预览**，60fps 跟手，
不影响游戏里的墙。

## 第二部分：触发器——这段动画"什么时候播"

做好动画后，还要回答一个问题：**它在游戏里啥时候动？** 这就是触发器。dock 设置里「什么时候播」：

### 2.1 手动 / 循环（默认）

墙一加载就自动播（如果是「循环播放」）。适合常驻的循环动画（呼吸灯、跑马灯）。

### 2.2 变量变了就播

绑定一个[变量](variables.md)，**那个变量一变化，这段动画就在游戏里播一遍**。

1. 「什么时候播」选 **变量变了就播**。
2. 下面出现「**点这里选要监听的变量**」按钮 → 点它 → 在弹出的选择器里挑一个变量。
3. 之后只要那个变量的值变了（玩家改、命令改、插件推、计分板变…），墙上的动画就播。

例子：绑定 `online`（在线人数）→ 有人上线人数一变，欢迎动画播一下；插件推一个「告警=真」→
招牌闪一下。

> 高频变量（比如每秒变的倒计时）绑上去会**去抖**（200 毫秒内的重复变化只播一次），不会疯狂重播。

### 2.3 到点就播（时刻表）

跟「变量变了就播」一样，只是专门绑[列车时刻表](variables.md)的 `schedule:*` 变量——**列车到点了，
"进站"动画自动播**。

## 第三部分：要知道的几件事

### 3.1 编辑期 vs 游戏内

- **编辑器里的预览**（播放头 / 播放按钮）始终是你本地的，随便拖、不影响别人。
- **游戏里部署的墙**：现在**编辑期间游戏里就能看到动画**了（循环动画一落键就在墙上动起来）。
- **触发器只作用于游戏里部署的墙**，编辑器预览不受触发器影响。

### 3.2 双端一模一样

编辑器里看到的动画和游戏里墙上出来的**逐帧一致**（同一套缓动 / 色彩数学，双端用同一组参照向量
在 CI 里把关）。所见即所得。

### 3.3 帧率

每条时间轴有自己的帧率（默认 20fps）。服主可在 `config.yml` 的 `timeline.max-fps` 设上限（默认 60）。
**系统不偷偷降帧**——你配多少就跑多少（够不够性能服主自己判断，见 `PROPOSAL.md §2.1`）。

### 3.4 撤销

关键帧编辑能 Ctrl+Z 撤销。一次"拉就设 / 加帧"是**一步撤销**（不会只撤掉六分之一）。

## 一分钟上手清单

1. 🎬 打开时间轴 → 新建
2. 选元素 → 确认红点（自动加帧）亮着
3. 播放头停 0 秒 → 拖元素到起点
4. 播放头拖到 2 秒 → 拖元素到终点
5. 选紫菱形块 → 调缓动（可选）
6. 设置里选「循环播放」+「手动/循环」→ 墙上就一直动了
7. 想"数据变了才播"？设置「什么时候播」→「变量变了就播」→ 选变量
